# חוזה · חוט hok-effectively-active
**תפקיד:** האם הוראת-הקבע של תומך **אפקטיבית-פעילה**. הו"ק ידני (בלי kevaId) ⇒ לפי
דגל active בלבד. הו"ק מנוהלת-סליקה (kevaId) ⇒ נחשבת פגה אם אין חיוב-נדרים/סולה
ב-hist מזה >2 חודשים אזרחיים (ביטול בנדרים לא שולח אירוע — החיובים פשוט נפסקים).
נגזרת בלי מוטציה ⇒ מתאוששת מאליה אם החיובים חוזרים.
**עוזר-פנימי מוטמע (לא שקע):** monthsAgoIso — חודשים-אזרחיים מאז ISO
(‏0=אותו חודש; ריק⇒Infinity). היה פרטי באותו קובץ-מקור והוטמע כלשונו.
**קלט:** sp (תומך: ‏hok{active,kevaId?,…} · ‏hist[]{clearer,d}) · todayIso. **פלט:** boolean.
**דוגמאות מחייבות (todayIso='2026-08-24'):**
1. ‏sp={} (בלי hok) → false. וגם ‏hok={active:false} → false.
2. הו"ק ידני: ‏hok={active:true, day:10} (בלי kevaId) → true (אין לאפ-אוטומטי).
3. ‏kevaId בלי שום hist → true (עדיין אין היסטוריית-נדרים — סומכים על הדגל).
4. ‏kevaId + ‏hist=[{clearer:'נדרים', d:'2026-06-15'}] → true (‏2 חודשים — בדיוק על הסף ≤2).
5. ‏kevaId + ‏hist=[{clearer:'נדרים', d:'2026-05-20'}] → false (‏3 חודשים — פגה).
6. 🐛 נחיל-סולה C7: ‏hist=[{clearer:'נדרים',d:'2026-04-10'},{clearer:'סולה',d:'2026-07-15'}]
   ‏+ kevaId → true (גם חיוב-סולה נחשב "חיות"; האחרון קובע).
7. ‏kevaId + ‏hist=[{clearer:'אשראי',d:'2026-08-01'},{clearer:'נדרים',d:'2026-03-01'}]
   → false (חיוב שאינו נדרים/סולה לא מחיה; הנדרים האחרון לפני 5 חודשים).
