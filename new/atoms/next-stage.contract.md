# חוזה · חוט next-stage
**תפקיד:** השלב הבא בשרשרת "מעקב-טיפול" (עין): מקבל שלב, מחזיר את הבא-אחריו
בסדר-השלבים; בשלב האחרון ⇒ null. שלב לא-מוכר ⇒ מתנהג כשלב-הראשון (דרך
נפילת-האפס של stageIndex) ומחזיר את השני.
**שקעים (חוק-1 — קריאה-לשכן הוזרקה כפרמטר):**
- ‏stageIndex(stage) ⇒ מספר — מיקום השלב בסדר (במקור: ‏indexOf; לא-נמצא ⇒ 0).
- ‏AYIN_STAGES — מערך-סדר-השלבים (במקור, קבוע:
  ‏['new','lead','eyes','answer','done']; התוויות-לתצוגה הן חיווט-termOf בקופסה).
**קלט:** stage (מחרוזת-שלב) · שני השקעים. **פלט:** מחרוזת-השלב-הבא או null.
**דוגמאות מחייבות** (עם AYIN_STAGES המקורי ו-stageIndex אמיתי — indexOf עם נפילה ל-0):
‏'new'→'lead' · ‏'lead'→'eyes' · ‏'eyes'→'answer' · ‏'answer'→'done' ·
‏'done'→null (השלב האחרון) · ‏'שטויות'→'lead' (לא-מוכר ⇒ אינדקס 0 ⇒ הבא הוא השני)
**מוצא:** maor/src/lib/ayin.ts:56-61 (‏nextStage, "השלב הבא, או null בשלב האחרון").
השכנים stageIndex + הקבוע AYIN_STAGES הפכו לשקעים (חוק-1).
