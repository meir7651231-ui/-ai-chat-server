# חוזה · חוט pin-needs-rehash
**תפקיד:** האם גיבוב-PIN שמור בפורמט-הישן וצריך שדרוג. גיבוב v2 = עדכני; כל
גיבוב-לגאסי (בלי קידומת `v2:`) = צריך רה-האש; גיבוב חסר/ריק ⇒ תמיד false.
**קלט:** `hash` — מחרוזת-גיבוב (או undefined/ריק).
**פלט:** בוליאני — `true` רק אם קיים גיבוב שאינו מתחיל ב-`v2:`.
**התנהגות:** `!!hash && !hash.startsWith('v2:')`. ריק/undefined ⇒ false (אין מה לשדרג).
**דוגמאות מחייבות:**
- ‏`'abc123'` → `true` (לגאסי — צריך שדרוג)
- ‏`'v2:salt:digest'` → `false` (כבר עדכני)
- ‏`''` → `false` (אין גיבוב)
- ‏`undefined` → `false` (אין גיבוב)
- ‏`'v2'` → `true` (אין נקודתיים — אינו מתחיל ב-`v2:`)

חולץ כלשונו.
