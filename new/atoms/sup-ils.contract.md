# חוזה · חוט sup-ils
**תפקיד:** **סה"כ ₪ של תומכת כולל היסטוריה** — המונה-השמור ‏ils
(קבלות-בלבד) + סכימת שורות הקובץ-ההיסטורי (hist) שאינן דולריות.
**הכרעת-בעלים 9.8 ("לכולל", סוגרת את ‎#14):** הצבירה **המוצגת** כוללת את
ההיסטוריה; המונים השמורים (count/ils/usd) נשארים קבלות-בלבד — אינווריאנט
הענן "מונים רק עולים" לא נגוע; ההכללה = נגזרת טהורה.
**קלט:** ‏sp — תומכת ‏{ils?, hist?:[{a,c?}]}. **פלט:** מספר — סה"כ ₪.
**דוגמאות מחייבות:**
1. ‏{ils:100} (בלי hist) ⇒ ‏100 — המונה השמור בלבד.
2. ‏{ils:100, hist:[{a:50,c:'₪'},{a:30,c:'$'}]} ⇒ ‏150 — שורת-$ מוחרגת
   (שייכת ל-supUsd).
3. ‏{} ⇒ ‏0 — ‏ils חסר ⇒ 0, ‏hist חסר ⇒ מערך ריק.
4. ‏{hist:[{a:70}]} ⇒ ‏70 — שורה בלי ‏c נספרת כשקלית (רק ‏c==='$' מוחרג).
5. ‏{ils:0, hist:[{a:25,c:'$'}]} ⇒ ‏0 — כולה דולרים ⇒ אפס ₪.
