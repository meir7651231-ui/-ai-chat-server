# חוזה · חוט build-course-daily-rows
**תפקיד:** דו"ח נוכחות יומי מפורט לחוג — מהתחלה עד סיום, מפגש-מפגש, מי פעילה
בכל מפגש כולל חיסורים. שורה ראשונה = כותרות (עמודת-המשפחה דרך termOf). סריקה
יום-יום בין start ל-end; יום נספר (‏days++) רק כשיש בו מפגש (‏sessions לפי
day===getDay; ‏c.sessions ריק ⇒ מפגש-ברירת-מחדל {day:weekday, time, label:''}).
לכל מפגש slot = ‏(label||'קבוצה')+' · '+time. תלמידה "פעילה" במפגש: לא-'wait',
‏enrolledAt≤iso (או חסר), קבוצה תואמת-label (או אחד מהם ריק), ו-'ended' רק
כש-‏endedAt קיים ו-iso<endedAt (שיבוץ-שהסתיים נשאר בהיסטוריה; בלי endedAt —
מוחרג). אין-פעילות ⇒ שורת 'אין רשומות'. סטטוס-יום: 'מוקפא' ל-paused, אחרת
'מתקיים'; נוכחות: 'מוקפא' / 'לא הופיעה' (noshow) / 'חיסור[ · סיבה]' / 'פעיל'.
תקרת-בטיחות MAX_DAYS=500 ימי-מפגש — מעבר ⇒ קטיעה + שורת-אזהרה עם
termOf('entity.course','חוג'). ‏start/end חסר ⇒ {rows:[כותרות], days:0}.
**שקעים (חוק-1):** ‏termOf(config,key,fb)⇒string (מילון-מונחים; נקרא רק כש-config
קיים — אחרת ה-fb) · ‏hebDateFull(iso)⇒string (תאריך-עברי מלא לתצוגה).
העוזרים DAY_NAMES/isoOf/fmtD היו פרטיים בקובץ-המקור — נשארו בתוך האטום.
**קלט:** c (חוג) · db{families,enrollments} · config? · שני השקעים.
**פלט:** ‏{rows: Cell[][], days: number}.
**דוגמאות מחייבות** (שקעי-בדיקה: ‏hebDateFull=iso⇒'ע:'+iso ·
termOf=(cfg,k,fb)⇒cfg.terms[k]??fb):
1. חוג ראשון 16:00, ‏start='2026-08-23' (ראשון) end='2026-08-30' (ראשון);
   שיבוצים: רות (active, ‏enrolledAt '2026-08-01', חיסור 30.8 בסיבה 'מחלה') ·
   יעל (wait) · נעמי (ended, ‏endedAt '2026-08-30', חיסור-noshow 23.8) ·
   תמר (paused) ⇒ ‏days=2, ‏rows.length=6 (כותרת+3+2):
   - שורת רות ב-23.8: ['ע:2026-08-23','23/08/2026','ראשון','קבוצה · 16:00',
     'מתקיים','רות','פרץ','פעיל']
   - נעמי ב-23.8: 'לא הופיעה'; ב-30.8 — איננה (‏iso<endedAt נכשל).
   - תמר בשני הימים: סטטוס-יום 'מוקפא' + נוכחות 'מוקפא'.
   - רות ב-30.8: 'חיסור · מחלה'. יעל (wait) לא מופיעה כלל.
2. ‏config={terms:{'entity.family':'לקוח'}} ⇒ כותרת[6]='לקוח'; בלי config ⇒ 'משפחה'.
3. ‏start='' ⇒ {rows:[כותרות בלבד], days:0}.
4. חוג בלי שיבוצים, מפגש אחד ב-23.8 ⇒ שורת 'אין רשומות' (שם/משפחה/נוכחות ריקים).
5. ‏sessions=[{day:0,time:'10:00',label:'א'},{day:0,time:'12:00',label:'ב'}],
   רות בקבוצה 'א', נעמי בלי קבוצה, יום 23.8 בלבד ⇒ ‏days=1; בסלוט 'א · 10:00'
   שתיהן, בסלוט 'ב · 12:00' רק נעמי (חסרת-קבוצה נכנסת לכל סלוט).
6. טעות-הקלדה בסיום: ראשון-שבועי מ-'2026-01-04' עד '2036-12-31', בלי שיבוצים ⇒
   ‏days=500, ‏rows.length=502, והשורה האחרונה:
   ['—','—','—','—','הדוח נקטע ב-500 ימי מפגש — בדקו את תאריך הסיום של החוג','','',''].
