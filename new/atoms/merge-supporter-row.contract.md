# חוזה · חוט merge-supporter-row
**תפקיד:** החלת שורת-ייבוא על כרטיס-תומכת קיים: ערך לא-ריק בשורה (אחרי trim)
דורס, ריק ⇒ נשמר הקיים; הטלפון עובר עיצוב דרך השקע; היסטוריה (אם יש בשורה)
ממוזגת אידמפוטנטית דרך השקע. **בלי קבלות, בלי נגיעה במונים/תרומות** — כל שאר
שדות-הכרטיס (donations/count/ils/…) עוברים כמו-שהם דרך ‎...sp‎. טהור.
**שקעים (חוק-1):**
- ‏mergeHist(existing, incoming) ⇒ היסטוריה ממוזגת אידמפוטנטית (האטום merge-hist).
- ‏fixPhone(p) ⇒ string — עיצוב טלפון ישראלי (האטום fix-phone).
**קלט:** sp (כרטיס קיים) · row (שורת-ייבוא: ‏name/phone/email/idNum/address/cat/forWho
מחרוזות חובה, ‏hist? אופציונלי). **פלט:** כרטיס מעודכן חדש.
**דוגמאות מחייבות (שקע-בדיקה: ‏fixPhone מוסיף מקף '050-'; ‏mergeHist=דדופ d|a|c):**
1. דריסה: ‏sp.name='דנה' + ‏row.name=' דנה לוי ' ⇒ ‏name='דנה לוי' (נגזם ודורס).
2. ריק נשמר: ‏row.email='   ' (רווחים) + ‏sp.email='d@x.co' ⇒ ‏email='d@x.co'.
3. טלפון דרך השקע: ‏row.phone=' 0501234567 ' ⇒ ‏fixPhone('0501234567') ⇒
   ‏'050-1234567'; ‏row.phone='' ⇒ ‏sp.phone נשמר וה-שקע **לא נקרא**.
4. היסטוריה: ‏sp.hist=[{d:'2026-01-01',a:100}] + ‏row.hist=[אותה רשומה,
   ‏{d:'2026-02-01',a:50}] ⇒ ‏hist באורך 2 (הכפולה מוזגה); ‏row בלי hist (או ריק)
   ⇒ ‏sp.hist נשאר כמו-שהוא וה-שקע לא נקרא.
5. הכסף לא זז: ‏sp עם ‏donations=[₪100], ‏count=1, ‏ils=100 ⇒ הפלט נושא אותם
   ערכים בדיוק, יהא תוכן-השורה אשר יהא.
