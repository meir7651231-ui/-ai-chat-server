# חוזה · חוט heb-to-iso
**תפקיד:** המרת תאריך עברי (יום + שם-חודש עברי + שנה עברית) לתאריך-ISO לועזי.
תווית-חודש לא-מוכרת ⇒ null; צירוף שלא קיים בשנה זו ⇒ null (דרך השקע).
**שקעים (חוק-1 — קריאה-לשכן הוזרקה כפרמטר):**
- ‏monthEnOf — ‏(monthHe)⇒שם-Intl אנגלי ('אב'→'Av') או null ללא-מוכר (טבלת 14 החודשים כולל אדר א׳/ב׳).
- ‏hebToIsoEn — ‏(day, monthEn, hebYear)⇒ISO או null (סריקת ~440 ימים מעוגן 1.8 של hebYear−3761; מאמת 1≤day≤30, 4000≤year≤7000).
**קלט:** day מספר · monthHe מחרוזת עברית · hebYear מספר (+2 השקעים). **פלט:** 'YYYY-MM-DD' או null.
**דוגמאות מחייבות (חושבו מול Intl לוח-hebrew, Node 22):**
1. ‏(23,'אב',5786) → '2026-08-06' (הדוגמה שבתיעוד-המקור).
2. ‏(1,'תשרי',5786) → '2025-09-23' (ראש-השנה — השנה העברית מתחילה בסתיו הלועזי הקודם).
3. ‏(15,'אדר א׳',5784) → '2024-02-24' (שנה מעוברת — אדר א׳ קיים).
4. ‏(15,'אדר א׳',5786) → null (שנה פשוטה — אין אדר א׳; הצירוף לא קיים).
5. ‏(30,'חשוון',5785) → '2024-12-01' אבל ‏(30,'חשוון',5786) → null (חשוון חסר בשנה זו).
6. ‏(10,'שטות',5786) → null (תווית-חודש לא-מוכרת — נעצר לפני השקע).
7. ‏(31,'אב',5786) → null וגם ‏(1,'אב',3000) → null (ולידציית-טווח בשקע hebToIsoEn).
