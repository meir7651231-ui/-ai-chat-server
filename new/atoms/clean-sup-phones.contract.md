# חוזה · חוט clean-sup-phones
**תפקיד:** ניקוי מערך-טלפונים לשמירה — `fixPhone` על כל מספר (אחרי trim),
סינון שורות שנותרו ריקות, שמירת שאר השדות.
**קלט:**
- `phones` — מערך `[{ num, ... }]` או `undefined`.
- `fixPhone` — **שקע** (חוט-שכן, מוזרק): `(num:string) ⇒ string` (עיצוב/נירמול; ריק⇒ריק).
**פלט:** מערך חדש, כל שורה `{ ...p, num: fixPhone(p.num.trim()) }`, בלי שורות ש-`num` שלהן ריק.
**התנהגות:** `undefined`⇒`[]` · `num` חסר/רווחים ⇒ נחתך ומסונן · שאר-השדות נשמרים.
**דוגמאות מחייבות (עם שקע `fx = s => s` — זהות):**
- ‏`undefined` → `[]`
- ‏`[]` → `[]`
- ‏`[{num:'  0501234567  ',label:'בית'}]` → `[{num:'0501234567',label:'בית'}]`
- ‏`[{num:''},{num:'0522222222'}]` → `[{num:'0522222222'}]`
- ‏`[{num:'   '}]` → `[]`
**דוגמה עם שקע-נירמול `fx = s => s.replace(/-/g,'')`:**
- ‏`[{num:'050-123',label:'x'}]` → `[{num:'050123',label:'x'}]`
**מוצא:** maor/src/components/supporters/lib.ts:300-304 (`cleanSupPhones`). במקור קרא
ל-`fixPhone` (=`formatIsraeliPhone`) מאותו מודול — כאן שקע-פרמטר (חוק-1).
