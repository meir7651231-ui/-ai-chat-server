# חוזה · חוט min-to-hm
**תפקיד:** דקות-מחצות ⇒ מחרוזת-שעה "HH:MM" (ריפוד אפסים דו-ספרתי). ההופכי של
timeToMin ביומן-החדרים. טהור.
**שקעים (חוק-1 — קריאת-שכן הוזרקה כפרמטר):**
- ‏pad2(n) ⇒ string — ריפוד לשתי ספרות (האטום pad2: ‏5⇒'05', ‏12⇒'12').
**קלט:** ‏min (מספר-דקות שלם) · ‏pad2. **פלט:** מחרוזת "HH:MM".
**דוגמאות מחייבות:**
1. ‏0 ⇒ '00:00' (חצות — שני חלקים מרופדים).
2. ‏75 ⇒ '01:15' (שעה + רבע).
3. ‏600 ⇒ '10:00'.
4. ‏59 ⇒ '00:59' (מתחת לשעה).
5. ‏1439 ⇒ '23:59' (הדקה האחרונה ביממה).
6. השקע נקרא **פעמיים** בדיוק: פעם עם השעות (⌊min/60⌋) ופעם עם השארית (min%60) —
   ל-75: ‏pad2(1) ואז ‏pad2(15).
