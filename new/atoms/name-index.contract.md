# חוזה · חוט name-index
**תפקיד:** אינדקס בני-משפחה לפי מזהה — בונה ‏Map מ-id לרשומת-החבר (עם שם-
המשפחה), לחיפוש O(1) בדוחות. מזהה כפול ⇒ האחרון-ברשימה מנצח (סמנטיקת
Map.set). טהור.
**שקעים (חוק-1 — קריאת-שכן הוזרקה כפרמטר):**
- ‏allMembers(db) ⇒ מערך כל בני-המשפחה בכל המשפחות (במקור: useApp.allMembers —
  כל חבר עם ‏id ושדות ‏famId/famName מוצמדים).
**קלט:** ‏db · ‏allMembers. **פלט:** ‏Map<id, member>.
**דוגמאות מחייבות (שקע-בדיקה מחזיר מערך קבוע):**
1. ‏allMembers ⇒ ‏[{id:'m1',name:'דנה'},{id:'m2',name:'יוסי'}] ⇒ ‏Map בגודל 2;
   ‏get('m1').name==='דנה' · ‏get('m2').name==='יוסי'.
2. הערך במפה הוא **אותו אובייקט** שהשקע החזיר (זהות-הפניה, לא עותק).
3. השקע נקרא **פעם אחת** בדיוק, עם ה-db שהוזרק (זהות-הפניה).
4. ‏allMembers ⇒ ‏[] ⇒ ‏Map ריק (גודל 0), ‏get('m1')===undefined.
5. מזהה כפול: ‏[{id:'m1',v:1},{id:'m1',v:2}] ⇒ גודל 1 ו-‏get('m1').v===2
   (האחרון מנצח).
**מוצא:** maor/src/components/reports/lib.ts:70-75 (‏nameIndex — מודול-הדוחות;
השכן allMembers מ-useApp הוזרק כשקע).
