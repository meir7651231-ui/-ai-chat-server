# חוזה · חוט parse-supporter-grid
**תפקיד:** פענוח רשת-תאים (‏string[][], מ-CSV או xlsx) לשורות-ייבוא תומכות —
טהור. **סורק את שורת-הכותרות** ב-15 השורות העליונות (הראשונה שמכילה מפתח-שם)
כדי לתמוך ביצוא-סליקה עם שורות-פתיח; זיהוי-עמודות לפי הכלה (טלפון/אימייל/
ת"ז/כתובת/קטגוריה/עבור). אין כותרת-שם ⇒ סדר-עמודות קבוע (0..6) מהשורה
הראשונה. עמודות סכום+תאריך ⇒ כל שורה נושאת גם עסקה ‏hist=[{d,a,…}] —
היסטוריה-ללא-קבלה (הכרעת-בעלים 9.8): סכום מנוקה-ומעוגל ל-2 ספרות; תאריך =
החלק שלפני הרווח, דרך parseAnyDate ואם נכשל והתא ספרתי — excelSerialToIso;
‏hist רק כש-amount>0 וגם תאריך תקין. מטא-דאטה (13.8): מטבע-דולר ⇒ ‏c:'$' ·
אסמכתא/מספר-עסקה/מספר-קבלה/מותג/ספרות/סולק/תשלומים/סטטוס — רק כשקיימים
בפועל (אחרת המפתח נעדר); סולק המכיל 'נדרים' מנורמל ל-'נדרים'. שורה בלי שם
מדולגת. אין אוטומט-עי"ן מקטגוריה (ביטול-בעלים 13.8).
**שקעים (חוק-1 — השכנים הוזרקו כפרמטרים):**
- ‏supNameKeys — מפתחות עמודת-השם. במקור: ‏SUP_NAME_KEYS=['שם','תורם'] (החוט sup-name-keys).
- ‏parseAnyDate(s) ⇒ ISO או '' — פענוח-תאריך סלחני (החוט parse-any-date).
- ‏excelSerialToIso(n) ⇒ ISO או '' — סריאל-Excel לתאריך (החוט excel-serial-to-iso).
(‏isFinite = גלובל-שפה, אינו שקע.)
**קלט:** rows ‏string[][] + 3 השקעים. **פלט:** מערך שורות-ייבוא
‏{name, phone, email, idNum, address, cat, forWho, hist?}.
**דוגמאות מחייבות (supNameKeys=['שם','תורם']; parseAnyDate: '09/08/26'→'2026-08-09',
אחרת ''; excelSerialToIso: 45878→'2025-08-09', אחרת ''):**
1. ‏[] → [].
2. כותרות ['שם','טלפון','אימייל','ת"ז','כתובת','קטגוריה','עבור'] + שורה
   ['דוד','050','a@b','123','רח 1','כללי','משה'] → ‏[{name:'דוד', phone:'050',
   email:'a@b', idNum:'123', address:'רח 1', cat:'כללי', forWho:'משה'}] (אין hist).
3. בלי כותרות: ‏[['דוד','050','a@b','1','כ','ק','ע']] → אותו מיפוי בסדר-קבוע
   (השורה הראשונה עצמה נקלטת — start=0).
4. שורות-פתיח: ‏[['יצוא'],['טווח'],
   ['שם','סכום','תאריך','מטבע','תשלומים','סטטוס','אסמכתא'],
   ['דוד','1,234.567','09/08/26 00:36','דולר','3','שולם','REF1']] → שורה אחת עם
   ‏hist=[{d:'2026-08-09', a:1234.57, c:'$', ref:'REF1', pays:3, status:'שולם'}]
   (כותרת בשורה-3; פסיק-אלפים מנוקה; עיגול ל-2 ספרות; השעה נחתכת;
   מפתחות-מטא שלא קיימים — נעדרים).
5. תאריך כסריאל-Excel: אותן כותרות + ['שרה','100','45878','','','',''] →
   ‏hist=[{d:'2025-08-09', a:100}] (‏parseAnyDate נכשל ⇒ המרה מסריאל).
6. עסקה פסולה: סכום '0' או תאריך 'אבג' → השורה נקלטת **בלי** hist.
7. סולק 'נדרים פלוס' → ‏clearer:'נדרים' (נרמול); שורה עם שם ריק → מדולגת.
