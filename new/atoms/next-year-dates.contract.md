# חוזה · חוט next-year-dates
**תפקיד:** תאריכי השנה הבאה לחוג — הזזת start/end שנה קדימה, שומר יום/חודש.
כל תאריך עובר: פרסור-צהריים ⇒ ‏setFullYear(+1) ⇒ החזרה ל-ISO. ‏29.2 בשנה
מעוברת ⇒ מתגלגל ל-1.3 בשנה הבאה (התנהגות Date הסטנדרטית).
**שקעים (חוק-1 — קריאה-לשכן הוזרקה כפרמטר):**
- ‏atNoon(iso) ⇒ ‏Date — פרסור ISO לצהריים-מקומי (מוסכמת-התאריכים של maor:
  `new Date(iso+'T12:00:00')` — בלי היסט UTC).
- ‏toIso(d) ⇒ מחרוזת ‏yyyy-mm-dd (ריפוד-אפסים, שדות מקומיים).
**קלט:** start · end (מחרוזות ISO) · שני השקעים.
**פלט:** ‏`{start, end}` — שניהם מוזזים שנה.
**דוגמאות מחייבות (עם atNoon/toIso אמיתיים):**
1. ‏('2025-09-01','2026-06-30') ⇒ ‏{start:'2026-09-01', end:'2027-06-30'}.
2. שנה מעוברת: ‏('2024-02-29','2024-06-30') ⇒ ‏{start:'2025-03-01', end:'2025-06-30'}.
3. חציית-מאה/ריפוד: ‏('1999-12-31','2000-01-05') ⇒ ‏{start:'2000-12-31', end:'2001-01-05'}.
4. אותו תאריך בשני הקצוות: ‏('2026-01-01','2026-01-01') ⇒ ‏{start:'2027-01-01', end:'2027-01-01'}.
