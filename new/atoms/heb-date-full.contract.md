# חוזה · חוט heb-date-full
**תפקיד:** "ט״ו אלול תשפ״ו" מתוך תאריך ISO — יום בגימטריה + חודש עברי (Intl
בעברית) + שנה בגימטריה. פרסור בצהריים-מקומי (`iso.slice(0,10)+'T12:00:00'`) ולא
בחצות: ‏`new Date('YYYY-MM-DD')` נפרש כחצות UTC, ובאזורי-זמן ממערב ל-UTC נופל
ליום הקודם ומטה את התאריך העברי ביום. ריק/שבור ⇒ ''.
**שקעים (חוק-1 — קריאות-לשכנים הוזרקו כפרמטרים; שלושתם אטומים קיימים):**
- ‏gem(n) ⇒ מחרוזת — גימטריה של יום (15→'ט״ו').
- ‏gemYear(y) ⇒ מחרוזת — גימטריה של שנה (‏+y%1000; '5786'→'תשפ״ו').
- ‏hebParts(d:Date) ⇒ ‏{day, month, year} — רכיבי-התאריך-העברי (נלקח רק day).
המחיצות בפלט: `gem(day) + ' ' + חודש-עברי + ' ' + gemYear(שנה)`; החודש והשנה
מ-Intl ‏he-u-ca-hebrew (מובנה — לא שקע).
**קלט:** iso (מחרוזת, גם עם זנב-שעה) · שלושת השקעים. **פלט:** מחרוזת.
**דוגמאות מחייבות (מאומתות מול הלוח, עם שקעים אמיתיים):**
‏'2026-08-24' → 'י״א אלול תשפ״ו' · ‏'2026-04-02' → 'ט״ו ניסן תשפ״ו' (פסח) ·
‏'2024-03-24' → 'י״ד אדר ב׳ תשפ״ד' (פורים במעוברת) ·
‏'2026-08-24T23:59:00' → 'י״א אלול תשפ״ו' (הזנב נחתך — slice(0,10)) ·
‏'' → '' · ‏'שטויות' → '' (תאריך שבור).
**מוצא:** maor/src/lib/hebrew.ts:156-161 (‏hebDateFull) — חולץ כלשונו; ‏fmtHM/fmtHY
(קבועי-Intl של הקובץ) הוטמעו פנימה (סטנדרט-שפה); ‏gem/gemYear/hebParts הפכו לשקעים.
