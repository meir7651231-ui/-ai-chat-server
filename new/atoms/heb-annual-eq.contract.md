# חוזה · חוט heb-annual-eq
**תפקיד:** שוויון יום+חודש עברי לחזרה שנתית (אזכרה/יום-הולדת/יום-נישואים) —
**א-סימטרי לפי תפקיד**: הארגומנט הראשון הוא *עוגן* (התאריך המקורי), השני הוא
*היום-הנבדק* בשנה הנוכחית. שני דיני-בעלים מוטמעים:
- **כלל ל׳** ("במקום ל אז א"): עוגן ל-30 בחודש שבשנת היום-הנבדק *אין בו* יום 30
  (חשוון/כסלו חסרים, אדר-א' בשנה פשוטה) ⇒ נופל על א' בחודש-הבא. דורש year בשאילתה.
- **כלל אדר** ("אדר רגיל → אדר ב׳"): שנה פשוטה — ה'אדר' היחיד בולע כל עוגן-אדר;
  שנה מעוברת — עוגן 'Adar'/'Adar II' ⇒ אדר ב׳ בלבד, עוגן 'Adar I' ⇒ אדר א׳ בלבד
  (בלי כפילות, בלי היעלמות).
**שקעים (חוק-1 — קריאה-לשכן הוזרקה כפרמטר):**
- ‏scanHebYear(hebYear) ⇒ ‏{seq: string[], has30: Set<string>} — רצף שמות-החודשים
  (Intl אנגלית) של השנה + קבוצת החודשים שיש בהם יום 30. נקרא רק בענף כלל-ל׳
  (עוגן-30 מול שאילתה-1 עם year).
**קלט:** anchor ‏{day, month} · query ‏{day, month, year?} · השקע scanHebYear.
חודשים בשמות Intl אנגליים ('Tishri', 'Adar II'…). **פלט:** boolean.
**דוגמאות מחייבות (מאומתות מול הלוח):**
‏{15,'Elul'} מול {15,'Elul'} → true · ‏{15,'Elul'} מול {14,'Elul'} → false ·
‏{14,'Adar'} מול {14,'Adar II',5784} → true (אדר-רגיל⇒אדר-ב׳ במעוברת) ·
‏{14,'Adar I'} מול {14,'Adar II',5784} → false · ‏{14,'Adar I'} מול {14,'Adar',5786} → true
(שנה פשוטה בולעת) · ‏{14,'Adar'} מול {14,'Nisan'} → false (אחד אדר, השני לא) ·
כלל ל׳: {30,'Heshvan'} מול {1,'Kislev',5786} → true (בתשפ"ו אין ל' חשוון) ·
‏{30,'Heshvan'} מול {1,'Kislev',5785} → false (בתשפ"ה יש ל' חשוון — אין נפילה) ·
‏{30,'Adar I'} מול {1,'Nisan',5786} → true (באג-האזכרה: 30 אדר-א' בשנה פשוטה
נופל על א' ניסן — ה'Adar' היחיד הוא הקודם-לניסן ואין בו 30).
**מוצא:** maor/src/lib/hebrew.ts:95-121 (‏hebAnnualEq) — חולץ כלשונו; ‏isAdar
(helper פרטי, שורות 50-52) הוטמע פנימה; ‏scanHebYear הפך לשקע.
