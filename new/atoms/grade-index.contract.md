# חוזה · חוט grade-index
**תפקיד:** אינדקס כיתה בסולם-הכיתות — סובלני לגרשיים (‏" ' ׳ ״ מוסרים),
לקידומת "כיתה" ולרווחים; ריק/לא-מזוהה ⇒ ‎-1.
**שקעים (חוק-1 — קבוע-שכן הוזרק כפרמטר):**
- ‏gradeOrder — סולם-הכיתות (בקוד-המקור: הקבוע GRADE_ORDER
  ‏['גן','א',…,'יב']; במחסן: החוט grade-order).
**קלט:** ‏g (מחרוזת-כיתה או undefined) · שקע-gradeOrder (מערך). **פלט:** מספר
(אינדקס מבוסס-0, או ‎-1).
**דוגמאות מחייבות** (בכולן ‏gradeOrder=['גן','א','ב','ג','ד','ה','ו','ז','ח','ט','י','יא','יב']):
1. ‏'גן' ⇒ **0**.
2. ‏'א' ⇒ **1**.
3. גרשיים מוסרים: ‏'י"ב' ⇒ **12**.
4. קידומת "כיתה" + גרש: ‏'כיתה ב׳' ⇒ **2**.
5. ריק ⇒ ‎**-1** · ‏undefined ⇒ ‎**-1**.
6. לא-מזוהה: ‏'יג' ⇒ ‎**-1**.
7. רווחים נגזמים: ‏' ה ' ⇒ **5**.
