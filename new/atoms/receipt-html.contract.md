# חוזה · receipt-html (חוט)
**מהות:** קבלה כ-HTML מוכן-להדפסה/PDF — טהור, מחרוזת בלבד; התוכן = בדיוק שורות-הטקסט
של הקבלה (שקע `receiptLines` = מקור-אמת יחיד), בפריסה רשמית: שורת מקור/העתק, גוף, RTL.
**מוצא:** ‏maor/src/lib/receipt.ts:165-195 (esc הפנימי נכלל).

## קלט/פלט
`receiptHtml(o, receiptLines)` — ‏o = פרטי-קבלה (חייב `rid`); ‏receiptLines = שקע ‎(o)⇒string[]‎.
מחזיר מחרוזת HTML מלאה (‎<!doctype…‎).

## ערבויות (ratchet)
1. **Escaping מלא** — ‏& < > בשם-תורם/ייעוד/כל-שורה לעולם לא מגיעים חיים ל-HTML (XSS).
2. שורות-ריקות מסוננות; השורה הראשונה = שורת-mark (מקור/העתק); השאר גוף לפי הסדר.
3. ‏dir="rtl" · lang="he" · charset=utf-8 · ‏@media print קיימים תמיד.
4. אפס-DOM ואפס-IO — פונקציה טהורה; אותו קלט ⇒ אותו פלט.
