# חוזה · חוט rooms-now
**תפקיד:** מצב-החדרים ברגע נתון (רצועת "חדרים LIVE", P2 פער 27): לכל חדר
**פעיל** מוחזר ‏{room, busyWith?} — ‏busyWith = החוג הראשון שמפגש שלו בחדר
חל באותו יום-שבוע והשעה בתוך ‏[תחילת-המפגש, תחילה+משך-המשבצת) — משך-המשבצת
= ‏room.slot או 60 דק׳. חדרים מושבתים (‏active=false) לא מוחזרים כלל.
‏now מוזרק (טוהר — בלי שעון פנימי). מפגש בלי time מדולג.
**שקעים (חוק-1 — קריאה-לשכן הוזרקה כפרמטר):**
- ‏sessionsOf(course) ⇒ מערך-מפגשים ‏[{day, time}] — המפגשים-בפועל של החוג
  (שכן באותו מודול; אטום נפרד). האטום קורא לו פר-חוג-מועמד.
**קלט:** ‏db (עם rooms·courses) · ‏now (Date) · השקע sessionsOf.
**פלט:** מערך ‏{room, busyWith?} — בסדר חדרי-db, רק פעילים.
**דוגמאות מחייבות** (‏sessionsOf = ‏(c)=>c.sessions||[]; ‏now = יום-שני 10:15 —
‏new Date('2026-08-24T10:15:00'), ‏getDay()=1):
1. ‏rooms=[r1 פעיל, r2 מושבת, r3 פעיל] ⇒ הפלט באורך 2 (r2 לא מוחזר).
2. חוג c1 ב-r1 (‏slot ברירת-מחדל) עם מפגש ‏{day:1, time:'10:00'} ⇒
   ‏busyWith=c1 (‏10:15 בתוך ‏[10:00,11:00)).
3. חוג c3 ב-r3 (‏slot:30) עם מפגש ‏{day:1, time:'09:40'} ⇒ ‏r3 פנוי
   (‏09:40+30=10:10 ≤ 10:15 — הקצה פתוח).
4. ‏now=10:00 בדיוק עם מפגש ‏'10:00' ⇒ תפוס (‏mins ≥ start כולל);
   ‏now=11:00 בדיוק עם ‏'10:00' ו-slot 60 ⇒ פנוי.
5. מפגש ביום אחר (‏day:2) או בלי ‏time ⇒ מדולג — החדר פנוי.
