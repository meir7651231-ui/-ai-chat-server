# חוזה · חוט open-cloud-key
**תפקיד:** חילוץ ה-DEK של הצפנת-הענן מ-envelope-מפתח (‏orgs/{slug}/_enc/envelope)
בעזרת סיסמה או מפתח-שחזור — האצלה **שקופה** לפותח-המעטפות: מעביר את
‏(env, secret, via) כלשונם ומחזיר את הערך-המוחזר כמו-שהוא (אותה Promise —
כולל null על סוד שגוי). האטום לא מוסיף שום התנהגות — קיומו מקבע את
חוזה-הענן בנפרד מחוזה-המכשיר, כך שמדיניות-ענן עתידית תוחלף בקופסה בלי
לגעת בפותח המקומי.
**שקע (חוק-1 — קריאה-לשכן הוזרקה כפרמטר):**
- ‏openDek(env, secret, via) — פותח-המעטפות (בקוד-המקור: import מ-crypto.ts).
**קלט:** env, secret, via ‏'pass'|'rec', והשקע openDek. **פלט:** בדיוק
הערך-המוחזר של openDek (‏===).
**דוגמאות מחייבות:**
1. שקע-מרגל שמחזיר זקיף S ⇒ ‏openCloudKey({iter:1000}, 'סוד', 'pass', spy)===S,
   והמרגל נקרא **פעם אחת** עם בדיוק ‏({iter:1000}, 'סוד', 'pass') — אותן רפרנסים.
2. ‏via='rec' מועבר כלשונו: המרגל מקבל 'rec'.
3. שקע שמחזיר ‏Promise.resolve(null) ⇒ הפלט (אחרי await) === null
   (סוד-שגוי מחלחל, לא נעטף).
