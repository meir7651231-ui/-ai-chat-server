# חוזה · חוט warehouse-value
**תפקיד:** ערך-מלאי כולל של המחסן — ‏Σ qty×cost על כל הפריטים, מעוגל לשקל שלם
(Math.round על הסכום הכולל, לא פר-פריט). ‏qty/cost חסר/לא-מספרי ⇒ 0 (‏+w||0).
**קלט:** warehouse — מערך ‏[{qty?, cost?…}].
**פלט:** מספר שלם.
**דוגמאות מחייבות:**
- ‏[{qty:10,cost:50}] → 500
- ‏[{qty:10,cost:50},{qty:3,cost:19.9}] → 560 (‏500+59.7=559.7 ⇒ עיגול-בסוף)
- ‏[{qty:3}] → 0 (בלי cost)
- ‏[{qty:'2',cost:'7'}] → 14 (קידום-מספרי של מחרוזות)
- ‏[{qty:'x',cost:50}] → 0 (לא-מספרי ⇒ 0)
- ‏[] → 0
