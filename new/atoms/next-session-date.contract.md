# חוזה · חוט next-session-date
**תפקיד:** מועד-המפגש הקרוב הבא של חוג (לזכאות-השלמה 48 שעות): לכל מפגש-שבועי
מחשבים את המופע הבא ביחס ל-`now` — אותו יום-בשבוע בשעת-המפגש; אם היום הוא
יום-המפגש והשעה **עוד לא עברה** ⇒ היום; עברה (או שווה) ⇒ בעוד שבוע. מחזיר את
המוקדם מבין כל המפגשים, או null כשאין מפגשים. שעה חסרה ⇒ '17:00'.
דטרמיניסטי — `now` מוזרק (ברירת-מחדל השעון, S7 20.8).
**שקעים (חוק-1 — קריאה-לשכן הוזרקה כפרמטר):**
- ‏sessionsOf(c) ⇒ מערך `{day,time,label}` — המפגשים-בפועל של החוג (במקור: נפילה
  למפגש-יחיד מ-`c.weekday`/`c.time` כשאין `c.sessions`). ‏day: ‏0=ראשון…6.
**קלט:** c (חוג) · now (‏Date מוזרק) · השקע sessionsOf. **פלט:** ‏Date או null.
**דוגמאות מחייבות** (‏now = ‏2026-08-24 יום-שני 12:00 מקומי = ‏new Date(2026,7,24,12,0);
השקע מחזיר את המערך הנתון):
1. ‏[{day:2,time:'17:00'}] ⇒ ‏שלישי 2026-08-25 17:00.
2. אותו יום, שעה עתידית: ‏[{day:1,time:'17:00'}] ⇒ **היום** 2026-08-24 17:00.
3. אותו יום, שעה שעברה: ‏[{day:1,time:'10:00'}] ⇒ בעוד שבוע 2026-08-31 10:00.
4. מרובה — המוקדם מנצח: ‏[{day:4,time:'09:00'},{day:2,time:'19:30'}]
   ⇒ ‏2026-08-25 19:30 (שלישי לפני חמישי).
5. בלי שעה: ‏[{day:3}] ⇒ ‏רביעי 2026-08-26 17:00 (ברירת-המחדל).
6. השקע מחזיר [] ⇒ null.
