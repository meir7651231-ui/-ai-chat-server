# חוזה · חוט read-file-as-data-url
**תפקיד:** קריאת קובץ-מסמך (לא-תמונה) ל-data-URL מוטמע (בקשת-בעלים 13.8 א׳) —
**שער-גודל** לפני הקריאה: קובץ מעל התקרה ⇒ זריקת שגיאה עברית עם התקרה ב-MB
והנחיה "הוסיפו קישור במקום"; אחרת מאציל לקורא. התקרה שמרנית (ברירת-מחדל
‏MAX_EMBED_BYTES = 3·1024·1024 = ‏3145728, מיוצא) כי המסמך המוטמע נשמר
ב-localStorage (~5MB למסמך כולו) ונוסע עם הסנכרון.
**שקעים (חוק-1 — קריאת-השכן הוזרקה כפרמטר):**
- ‏readAsDataUrl(file) ⇒ ‏Promise<string> — הקורא בפועל (במקור: שכן פרטי על
  ‏FileReader של הדפדפן; בהצבת-דפדפן מזריקים אותו בקופסה).
**קלט:** ‏file (עם ‏size מספרי) · ‏readAsDataUrl · ‏maxBytes (ברירת-מחדל
‏MAX_EMBED_BYTES). **פלט:** ‏Promise<string> (data-URL) או זריקה.
**דוגמאות מחייבות:**
1. ‏size=3145729 (3MB+1), ברירת-מחדל ⇒ זריקה
   ‏'הקובץ גדול מדי להטמעה (מקסימום 3MB) — הוסיפו קישור במקום', והשקע
   **לא נקרא כלל**.
2. ‏size=3145728 (בדיוק התקרה — לא מעל) ⇒ עובר: השקע נקרא פעם אחת עם הקובץ
   עצמו, והתוצאה היא בדיוק מה שהשקע החזיר
   (‏'data:application/pdf;base64,AA==').
3. ‏maxBytes=1048576 (1MB), ‏size=2000000 ⇒ ההודעה נוקבת ‏'מקסימום 1MB'
   (התקרה שבהודעה נגזרת מ-maxBytes, לא מגודל-הקובץ).
4. עיגול: ‏maxBytes=2621440 (2.5MB), ‏size=3000000 ⇒ ‏'מקסימום 3MB'
   (‏Math.round(2.5)=3).
5. השקע נדחה (‏reject Error('קריאת הקובץ נכשלה')) ⇒ השגיאה מבעבעת החוצה.
**מוצא:** maor/src/lib/imagePick.ts:39-46 (‏readFileAsDataUrl + ‏MAX_EMBED_BYTES).
חולץ כלשונו; השכן הפרטי ‏readAsDataUrl (דפדפן) הפך לשקע (חוק-1).
