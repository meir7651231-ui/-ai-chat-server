# חוזה · חוט name-sort-key
**תפקיד:** מפתח-שם **חסין-סדר** להשוואת-כפילויות (נדרים משפחה-קודם "בן צבי רחל"
מול מאור פרטי-קודם "רחל בן צבי"): נרמול → פיצול-מילים → הסרת-תארים →
**מיון** → חיבור ברווחים. כך "בן צבי רחל" ≡ "רחל בן צבי". ריק כשאין ≥1 טוקן.
**שקעים (חוק-1 — קריאות-לשכנים הוזרקו כפרמטרים):**
- ‏normSearch — ‏(string)⇒string, נרמול-חיפוש עברי (במקור: מסיר ניקוד, אותיות
  סופיות→רגילות, גרשיים/מקפים; ‏String(t||'') ⇒ בטוח גם ל-null).
- ‏nameTitles — ‏Set<string> של תארים/כינויי-כבוד להסרה כטוקן-שלם (במקור:
  קבוע-שכן NAME_TITLES — 'הרב','מר','משפחת','שליטא','זצל'…; לא כולל בן/בר).
**קלט:** מחרוזת-שם + שני השקעים. **פלט:** מפתח-מיון (מחרוזת).
**דוגמאות מחייבות** (עם normSearch-המקור ו-titles={'הרב','מר','משפחת'}):
1. ‏'רחל בן צבי' ⇒ ‏'בנ צבי רחל' (‏ן-סופית נורמלה ל-נ; מיון UTF-16: ב<צ<ר).
2. ‏'בן צבי רחל' ⇒ ‏'בנ צבי רחל' — זהה ל-1 (חסין-סדר).
3. ‏'הרב משה כהן' ⇒ ‏'כהנ משה' — התואר הוסר; ן-סופית נורמלה ל-נ; כ<מ.
4. ‏'מרים לוי' ⇒ ‏'לוי מרימ' — 'מרים'≠'מר': תואר מוסר רק כטוקן-שלם.
5. ‏'' ⇒ ‏'' (אפס טוקנים) · ‏'משפחת' ⇒ ‏'' (רק תואר ⇒ ריק).
