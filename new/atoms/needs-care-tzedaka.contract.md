# חוזה · חוט needs-care-tzedaka
**תפקיד:** רשימת-הטיפול של מודול-קופות-הצדקה, בסדר קבוע: קופות מוזנחות
(stale) → אבודות (lost) → רכזים לא-פעילים שעדיין מחזיקים קופות-בבתים
(inactiveCoord) → מבצעים שמסתיימים בתוך 14 יום (campaignEnding).
כל התרעה: ‏{kind, id, label, hint}. מונח-הקופה עובר termOf כשיש config;
בלי config ⇒ 'קופה'. תצוגה-בלבד, אפס כתיבה.
**שקעים (חוק-1 — קריאות-לשכנים הוזרקו כאובייקט-sockets רביעי):**
- ‏termOf(config, key, fallback) ⇒ string — מילון-המונחים (‏'entity.tzBox').
- ‏staleBoxes(tzBoxes, todayIso) ⇒ קופות שלא רוקנו מזמן (מדיניות-הסף אצל השכן).
- ‏lastCollectionIso(box) ⇒ IsoDate|'' — ריקון אחרון.
- ‏coordinatorBoxes(tzBoxes, coordId) ⇒ הקופות של רכז.
- ‏isoOf(date) ⇒ 'YYYY-MM-DD' (לחישוב חלון ה-14 יום; ‏T12:00:00 צהריים-מקומי).
**קלט:** ‏db (tzBoxes/tzCoordinators/tzCampaigns) · todayIso · config|undefined · sockets.
**פלט:** מערך-התרעות בסדר-הקבוע לעיל.
**דוגמאות מחייבות** (todayIso='2026-08-24', שקעי-בדיקה דטרמיניסטיים):
1. קופה מוזנחת ‏{num:3} עם ריקון-אחרון ‏'2026-01-01' ⇒ ‏{kind:'stale',
   label:'קופה 3 לא רוקנה מזמן', hint:'ריקון אחרון: 2026-01-01'}.
2. מוזנחת שמעולם-לא-רוקנה עם ‏since:'2025-05-01' ⇒ hint
   ‏'מעולם לא רוקנה (מאז 2025-05-01)'; בלי since ⇒ ‏'מעולם לא רוקנה (מאז —)'.
3. קופה ‏{num:7, status:'lost'} ⇒ ‏{kind:'lost', label:'קופה 7 מסומנת כאבודה',
   hint:'לברר או להוציא משימוש'}.
4. רכז לא-פעיל 'ראובן' עם 2 קופות ‏status:'home' ⇒ ‏{kind:'inactiveCoord',
   label:'ראובן אינו פעיל אך עדיין עם 2 קופות בבתים'}; עם 0 בבתים ⇒ אפס התרעה.
5. מבצע פעיל ‏end:'2026-09-01' (בתוך 14 יום, ‏soonIso='2026-09-07') ⇒
   ‏{kind:'campaignEnding', label:'המבצע "אלול" מסתיים ב-2026-09-01'};
   ‏end:'2026-09-20' (מעבר לחלון) או מבצע לא-פעיל ⇒ אפס התרעה.
6. עם config ו-termOf⇒'קופסה' ⇒ התוויות נפתחות ב-'קופסה 3 …' (המונח מוזרם).
