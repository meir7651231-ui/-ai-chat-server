# חוזה · חוט sup-last-in-period
**תפקיד:** האם **התרומה האחרונה** של התורם נפלה בתקופה — שנה (yyyy) ו/או חודש
(1–12); ‏null=כל. משלים את supGaveInPeriod (שבודק אם נתן **בכלל** בתקופה): כאן
נבדקת רק האחרונה ("מי שתרם לאחרונה ב-…", בקשת-בעלים "סינון לפי תרומה אחרונה
של הלקוח"). תורם בלי אף תרומה ⇒ false (לא-נכלל) — אלא אם אין שום סינון (שניהם null).
**שקעים (חוק-1 — קריאה-לשכן הוזרקה כפרמטר):**
- ‏supLast(sp)⇒string — ה-ISO של התרומה האחרונה (קבלות+היסטוריה), '' כשאין
  (קיים גם כחוט sup-last; כאן שקע — אטום לא מייבא אטום, הקופסה תחווט).
**קלט:** ‏sp · ‏year: number|null · ‏month: number|null · השקע. **פלט:** boolean.
**דוגמאות מחייבות (שקע-הבדיקה: ‏supLast=(sp)⇒sp.last||''‏):**
1. ‏year=null, month=null ⇒ true תמיד — גם לתורם בלי תרומות ({}).
2. ‏{last:'2026-08-24'}, year=2026, month=null ⇒ true.
3. ‏{last:'2026-08-24'}, year=2025, month=null ⇒ false (שנה אחרת).
4. ‏{last:'2026-08-24'}, year=2026, month=8 ⇒ true; ‏month=7 ⇒ false.
5. ‏{last:'2026-08-24'}, year=null, month=8 ⇒ true (סינון-חודש בלבד, כל שנה).
6. ‏{} (אין תרומה), year=2026 ⇒ false (תורם בלי תרומה לא-נכלל).
