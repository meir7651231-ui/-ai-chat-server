# חוזה · חוט parse-ayin-sheet
**תפקיד:** פענוח גיליון-העיניים שחזר מהשטח (round-trip, legacy:852-869) —
טהור. זיהוי-עמודות לפי **הכלה** בכותרות שורה-1 (תומכת/שם למסירה/עיניים/נמסר/
שולם/תשובה/עופרת); לכל שורה: התאמת תומכ/ת+שם ב-normName (עמודת-תומכת ריקה ⇒
התאמה לפי השם בלבד); ‏yes() לפי ‏/כן|yes|✓|v|שולם/i; ‏eyes = ספרות-בלבד
(‏eyes=0 תקין; אחר ⇒ null); שורה בלי שום ערך (עיניים/נמסר/שולם/תשובה/עופרת)
מדולגת בשקט; שם שלא נמצא ⇒ ‏miss++. פחות מ-2 שורות ⇒ שגיאת "הקובץ ריק";
חסרה עמודת שם/עיניים ⇒ שגיאת עמודות-חובה (בשתיהן upds ריק).
**שקע (חוק-1 — קריאה-לשכן הוזרקה כפרמטר):**
- ‏normName(s) — נרמול-שם להשוואה. במקור: ‏normName מ-lib/validate
  (‏normSearch + הסרת כל הרווחים). הנרמול עצמו — מדיניות-הקופסה (החוט norm-name).
**קלט:** rows ‏string[][], supporters (עם ‏id/name/ayin.names[{id,name}]), normName.
**פלט:** ‏{upds:[{supporterId,nameId,eyes,done,paid,answer,lead}], miss, error?}.
**דוגמאות מחייבות (normName = lowercase + הסרת-רווחים; תומכת s1='רחל כהן' עם
ayin.names: n1='משה בן שרה', n2='דוד'; כותרות
['תומכת','שם למסירה','כמה עיניים','נמסר','שולם','תשובה','עופרת']):**
1. ‏rows=[header] בלבד → {upds:[], miss:0, error:'הקובץ ריק או לא בפורמט CSV'}.
2. כותרות בלי 'עיניים' → error:'חסרות עמודות "שם למסירה" ו/או "כמה עיניים"'.
3. ‏['רחל כהן','משה  בן שרה','5','כן','','',''] → upd
   ‏{supporterId:'s1', nameId:'n1', eyes:5, done:true, paid:null, answer:null, lead:null}
   (רווח-כפול נבלע ב-clean; ‏paid/answer/lead ריקים ⇒ null).
4. ‏['','דוד','0','','שולם','יש תשובה','כן'] → ‏{supporterId:'s1', nameId:'n2',
   eyes:0, done:null, paid:true, answer:'יש תשובה', lead:true} (תומכת ריקה ⇒
   התאמת-שם בלבד; ‏eyes=0 תקין; 'שולם' עובר yes).
5. ‏['רחל כהן','לא קיים','3','','','',''] → אפס upds · miss=1.
6. ‏['רחל כהן','דוד','','','','',''] → מדולגת בשקט (אפס upds, אפס miss).
7. ‏['רחל כהן','דוד','אבג','','','',''] → מדולגת ('אבג' אינו ספרות ⇒ eyes=null,
   ואין שום ערך אחר).
