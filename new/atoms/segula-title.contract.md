# חוזה · חוט segula-title
**תפקיד:** כותרת-תצוגה לתזכורת-סגולה — שם-התורם + "יום N/יעד". תזכורת-סיום
(`r.final`) מקבלת קידומת 🎯, השאר 🕯.
**קלט:**
- `name` — שם-התורם (מחרוזת; ריק/undefined ⇒ מחרוזת ריקה).
- `r` — תזכורת `{ day, final }` (מ-segula-reminders).
- `target` — מספר-היעד (למכנה "יום N/יעד").
**פלט:** מחרוזת `<אייקון+תווית> — <שם> · יום <r.day>/<target>`.
**התנהגות:** `(r.final ? '🎯 סיום סגולה' : '🕯 סגולה') + ' — ' + (name||'') + ' · יום ' + r.day + '/' + target`.
**דוגמאות מחייבות (target=40):**
- ‏`('משה', {day:1,final:false}, 40)` → `'🕯 סגולה — משה · יום 1/40'`
- ‏`('משה', {day:40,final:true}, 40)` → `'🎯 סיום סגולה — משה · יום 40/40'`
- ‏`('', {day:7,final:false}, 40)` → `'🕯 סגולה —  · יום 7/40'`
- ‏`(undefined, {day:21,final:false}, 40)` → `'🕯 סגולה —  · יום 21/40'`
- ‏`('רבקה', {day:35,final:false}, 40)` → `'🕯 סגולה — רבקה · יום 35/40'`
