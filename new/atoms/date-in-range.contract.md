# חוזה · חוט date-in-range
**תפקיד:** האם תאריך-ISO בטווח **כוללני** — קצה ריק = פתוח. השוואה
לקסיקוגרפית על ISO (YYYY-MM-DD ממוין כמו תאריך). ה-helper המשותף לסינוני-
ההיסטוריה (קופות/חנות — בלי כפל-לוגיקה).
**קלט:** ‏iso · ‏fromIso · ‏toIso (מחרוזות ISO; ריק=פתוח). **פלט:** boolean.
**דוגמאות מחייבות:**
1. ‏('2026-08-24','2026-08-01','2026-08-31') ⇒ true (באמצע).
2. גבול-תחתון כוללני: ‏('2026-08-01','2026-08-01','2026-08-31') ⇒ true.
3. גבול-עליון כוללני: ‏('2026-08-31','2026-08-01','2026-08-31') ⇒ true.
4. לפני הטווח: ‏('2026-07-31','2026-08-01','2026-08-31') ⇒ false.
5. אחרי הטווח: ‏('2026-09-01','2026-08-01','2026-08-31') ⇒ false.
6. קצה פתוח: ‏('1999-01-01','','2026-08-31') ⇒ true · ‏('2999-01-01','2026-08-01','') ⇒ true.
7. שני הקצוות ריקים ⇒ true לכל תאריך.
