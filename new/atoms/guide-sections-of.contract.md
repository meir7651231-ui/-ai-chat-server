# חוזה · חוט guide-sections-of
**תפקיד:** שורות-המדריך 📖 למצב-מערכת נתון — סינון לפי מודולים פעילים (שורה
בלי ‏module **תמיד** נשארת: בית/הגדרות) + תרגום מונחי-ישות פר-עסק: הכותרת
'כרטיס משפחה' ⇒ 'כרטיס <משפחה>'; בגוף מוחלפים 'חדרים חיים' / 'על חדר' /
'בתוך חוג' / 'תדפיס למורה' / '＋ תרומה' / 'שיוך למשפחה' לפי המונחים. בלי
‏config ⇒ הנוסח מהלגאסי מילה-במילה (ratchet), ושורה שלא השתנתה מוחזרת
**באותה זהות-אובייקט** (‏===). כותרות עם ‏term מתורגמות ברכיב — לא כאן.
**שקעים (חוק-1 — קריאות-שכנים הוזרקו כפרמטרים):**
- ‏sections ⇒ ‏GuideSection[] — שורות-המקור ‏{module?,term?,title,text}
  (במקור: הקבוע GUIDE_SECTIONS; במחסן: אטום-הקבוע guide-sections).
- ‏termOf(config,key,fallback) ⇒ string — מונח פר-עסק או ה-fallback
  (במחסן: החוט term-of). נקרא רק כש-config מוגדר.
- ‏swap(s,from,to) ⇒ string — החלפת תת-מחרוזת גלובלית בלי regex
  (במקור: ‏s.split(from).join(to) — guide.ts:91-93).
**קלט:** ‏isModuleOn(m)⇒boolean · ‏config (אופציונלי) · שלושת השקעים.
**פלט:** מערך השורות המסוננות-מתורגמות.
**דוגמאות מחייבות** (סעיפי-הדוגמה: ‏S1={title:'בית',text:'תקציר הבוקר, חדרים חיים וגרפים.'} ·
‏S2={module:'families',title:'כרטיס משפחה',text:'ניקוב ✓, 📜 היסטוריה.'} ·
‏S3={module:'courses',term:'nav.courses',title:'קורסים',text:'בתוך חוג: שיבוץ, ⬇ תדפיס למורה.'};
השקעים: ‏swap חוזי · ‏termOf(cfg,k,fb)=cfg.terms[k]||fb):
1. בלי ‏config, הכול פעיל ⇒ ‏[S1,S2,S3] מילה-במילה, **באותה זהות** (‏[0]===S1).
2. ‏courses כבוי ⇒ ‏[S1,S2] — ‏S3 נשמט; ‏S1 בלי module נשאר.

   'בתוך סדנה: שיבוץ, ⬇ תדפיס למדריכה.'.
5. ‏config עם ‏{'entity.rooms':'אולמות'} ⇒ טקסט ‏S1 = 'תקציר הבוקר, אולמות חיים וגרפים.'.
