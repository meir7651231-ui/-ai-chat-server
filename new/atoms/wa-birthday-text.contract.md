# חוזה · חוט wa-birthday-text
**תפקיד:** נוסח ברכת יום-ההולדת לחוגג/ת, שנפתח בוואטסאפ לעריכה לפני שליחה.
האטום מעביר את משתני-התבנית כמות-שהם: ‏first = ‏firstName (בלי טרים ובלי תוספת) ·
‏org = שם-הארגון דרך שקע-orgOf, ומרנדר את תבנית 'wa.birthday' דרך שקע-renderTemplate.
**שקעים (חוק-1 — קריאה-לשכן הוזרקה כפרמטר):**
- ‏renderTemplate(cfg, key, vars) ⇒ string — מנוע-התבניות של maor
  (‏lib/templates.ts:57-66): דריסת-ארגון ‏cfg?.templates?.[key] מקוצצת; ריקה ⇒
  ברירת-המחדל ההיסטורית של 'wa.birthday': ‏'מזל טוב ל{first} ליום ההולדת! 🎂 באהבה, {org}';
  החלפת ‏{var} טקסטואלית (split/join).
- ‏orgOf(orgName) ⇒ string — ‏wa.ts:47-49: ‏orgName.trim() ריק ⇒ 'העמותה'.
**קלט:** orgName · firstName · cfg (אופציונלי — ‏{templates?}) · שני השקעים.
**פלט:** מחרוזת-ברכה.
**דוגמאות מחייבות (עם שקעי-אמת כהתנהגות maor):**
‏('מאור החסד','שרה',undefined)→'מזל טוב לשרה ליום ההולדת! 🎂 באהבה, מאור החסד' ·
‏('  ','דוד',undefined)→'מזל טוב לדוד ליום ההולדת! 🎂 באהבה, העמותה' (נפילת-ארגון) ·
‏('מאור','',undefined)→'מזל טוב ל ליום ההולדת! 🎂 באהבה, מאור' (שם ריק עובר כמות-שהוא) ·
‏('מאור','שרה',{templates:{'wa.birthday':'{first} — מזל טוב מ{org} 🎈'}})→'שרה — מזל טוב ממאור 🎈' (דריסת-ארגון)
