# חוזה · חוט slugify
**תפקיד:** גזירת סלאג משם-ארגון: תעתיק עברית→לטינית (טבלת HEB2LAT מוטבעת),
אותיות-קטנות/ספרות/מקפים בלבד, אורך 2–30, ייחודי מול רשימת-התפוסים
(סיומת ‎-2, ‎-3 …). ריק/קצר-מדי אחרי ניקוי ⇒ 'org'.
**קלט:** ‏orgName (מחרוזת) · ‏taken (מערך סלאגים תפוסים). **פלט:** מחרוזת-סלאג.
**דוגמאות מחייבות:**
1. ‏slugify('מאור החסד', []) → 'mavr-hchsd' (תעתיק: מ=m א=a ו=v ר=r · ה=h ח=ch ס=s ד=d; רווח ⇒ מקף).
2. ‏slugify('Café! 123', []) → 'caf-123' (‏é ו-! אינם ‎a-z0-9 ⇒ קורסים למקף אחד).
3. ‏slugify('א', []) → 'org' (אחרי ניקוי נותר 'a' — קצר מ-2 ⇒ ברירת-המחדל).
4. ‏slugify('maor', ['maor']) → 'maor-2' · ‏slugify('maor', ['maor','maor-2']) → 'maor-3' (ייחודיות בסיומת עולה).
5. ‏slugify('a'.repeat(35), []) → 'a'.repeat(30) (קיצוץ ל-30 תווים).
6. ‏slugify('a'.repeat(29) + ' b', []) → 'a'.repeat(29) (הקיצוץ חתך על המקף ⇒ מקפי-סוף נגזמים).
