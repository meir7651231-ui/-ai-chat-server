# חוזה · קופסת-זיהוי-השיחה (new/boxes/caller-id.mjs)
**מהות:** נקודת-החיבור של screen-pop: מספר-גולמי ⇒ מתקשר-מזוהה + תווית-מונחים + הקשר.

## חיווט (הכרעות)
- `identifyCaller(db, raw)` = ‏find-caller עם שקע-הנירמול phone-key.
- `kindLabel(cfg, kind)` = ‏caller-kind-label עם ‏term-of האמיתי — white-label חי.
- `screenPop(db, cfg, raw)` — הרכבה: מתקשר+תווית+הקשר-משפחה (משפחה/בן-משפחה בלבד).

## ערבויות-קצה
1. סדר-הקדימות נשמר: משפחה → בן-משפחה → תורם → מתנדב → רכז (הראשון מנצח).
2. מספר קצר (<6 ספרות אחרי נירמול) ⇒ null — אין false-positive.
3. ‏0501234567 ≡ ‎+972-50-1234567‎ ≡ 00972501234567 (מפתח-השוואה אחיד).
4. תווית ללא-דריסות = ההיסטורית בדיוק (ביט-זהה ללקוח-החי); עם דריסות = המונח-הנדרס.
5. הקשר-משפחה רק למשפחה/בן-משפחה; לתורם/מתנדב/רכז ⇒ context=null.
