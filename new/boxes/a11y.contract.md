## חשיפה (הכול טהור — אפס DOM/localStorage בקופסה)
- `SCALE_MIN` · `SCALE_MAX` · `SCALE_STEP` — קבועי-הסולם, מיוצאים מהחוטים (a11y.ts:13-15).
- `A11Y_FAB_TOGGLES` — 4 המתגים **בסדר ובנוסח הלגאסי** (a11y.ts:27-32):
  `['contrast','ניגודיות גבוהה']` → `['links','הדגשת כפתורים וקישורים']` →
  `['noanim','עצירת אנימציות ותנועה']` → `['spacing','ריווח טקסט מוגדל']`.
- `clampScale(v) ⇒ number` — **הכרעה 1:** גבולות-הזום של הלגאסי מוזרקים לחוט:
  `clampScaleAtom(v, SCALE_MIN, SCALE_MAX)` (a11y.ts:35-38). לא-מספרי ⇒ 1 (ברירת-המחדל,
  ‏a11y.ts:34,36).
- `stepScale(v, dir) ⇒ number` — **הכרעה 2:** הצעד = `SCALE_STEP` וההצמדה דרך
  `clampScale` המחווט-כאן: `stepScaleAtom(v, dir, clampScale, SCALE_STEP)` (a11y.ts:44-46);
  העיגול-לעשירית של הלגאסי (script:3193) חי בחוט — ‏1.1+0.1=1.2 בדיוק, בלי שאריות float
  (a11y.ts:41-43).
- `parseAcc(raw) ⇒ {contrast,noanim,links,spacing}` — קלט פגום/חלקי/null מתקבל בשקט
  כברירות-מחדל (הכול false, a11y.ts:48-58).

## דוגמאות מחייבות (מספריות)
- `clampScale(2) = 1.6` · `clampScale(0.5) = 0.8` · `clampScale(1.2) = 1.2` ·
  `clampScale(NaN) = 1` · `clampScale(Infinity) = 1` · `clampScale('1.2') = 1`
  (מחרוזת אינה מספר — Number.isFinite).
- `stepScale(1, 1) = 1.1` · `stepScale(1.1, 1) = 1.2` **בדיוק** (=== 1.2, לא 1.2000000000000002) ·
  `stepScale(1.6, 1) = 1.6` (רוויה בתקרה) · `stepScale(0.8, -1) = 0.8` (רוויה ברצפה) ·
  `stepScale(NaN, 1) = 1.1` (לא-מספרי ⇒ 1 ⇒ צעד אחד).
- `parseAcc(null)` ⇒ הכול false · `parseAcc('{"contrast":true}')` ⇒ רק contrast ·
  `parseAcc('לא-JSON{')` ⇒ הכול false · `parseAcc('"עברית"')` ⇒ הכול false ·
  `parseAcc('{"contrast":1,"links":"כן"}')` ⇒ contrast+links true (כפיית-!!) ·
  `parseAcc('null')` ⇒ הכול false.
