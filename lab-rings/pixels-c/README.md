# pixels-c — תוכניות-תמונה מדויקות, בשפת C

אותו רעיון כמו `pixels/`: המנוע מקבל תמונה וכותב תוכנית שמציירת אותה בחזרה פיקסל-פיקסל, בלי שום הבדל.
ההבדל: התוכנית שיוצאת היא קובץ C אחד (במקום פייתון), והמקודדים עצמם מהירים יותר.

```
gcc -O2 results/predict/wall.c -o wall -lm && ./wall out.ppm      # predict
gcc -O2 results/dict/wall.c -o wall -llzma -lm && ./wall out.ppm  # dict (קבצי dict/new צריכים liblzma)
python3 ../pixels/compare.py out.ppm original.png                 # 0 different
```

- `predict/` — חיזוי מהשכנים + קידוד אריתמטי. `engine.py --c` כותב את קובץ ה-C, `pxenc.c` הוא המקודד המהיר.
- `dict/` — מילון טלאים + LZMA/CM. `engine.py --c`, `dictcm.c`.
- `results/` — 8 התוכניות המוכנות (4 תמונות × 2 מנועים) עם הנתונים שלהן.
- `bench/` — סקריפטי המדידה (נכתבו לפריסת ה-scratchpad המקורית).

תוצאות שנבדקו שוב באופן עצמאי (`VERIFY.txt`): כל 8 התוכניות מציירות 0 פיקסלים שונים.
פענוח: 1.9–4.6 שניות במקום 2–3 דקות בפייתון (פי 30–95). התוכניות קטנות ב-2–15% מגרסת הפייתון.
קידוד: dict מהיר פי 9–11; predict מהיר רק פי 0.9–1.8 (על התמונה הקטנה הוא אפילו קצת יותר איטי).
התוכנית לא קוראת שום קובץ — רק כותבת את התמונה (נבדק עם strace).
