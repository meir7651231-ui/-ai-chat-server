# פעולות-היסוד

פעולות שאי אפשר לפרק יותר. כל פעולה אחרת בנויה מהן.
השיטה: לכל פעולה שואלים «כמה סוגים יש?» ומפרקים עד שנשאר אחד.

---

## 1. לאן
**מה:** כתובת כתובה.
**כמה סוגים:** אחד.
- לפי שם ⇒ הולכים לטבלה (כתובת כתובה) ולוקחים ממנה כתובת כתובה.
- לפי חישוב («הבא בתור») ⇒ מחשבים, והתוצאה היא כתובת כתובה.

## 2. לך
**מה:** ללכת לכתובת.
**כמה סוגים:** אחד.
- ללכת למקום שיש בו דבר (כדי לקחת או לשים) = אותה פעולה.
- ללכת לשורה אחרת בקוד («קפוץ», «חזור להתחלה», «חזור למי שקרא») = אותה פעולה. ההבדל רק מה יש בכתובת: דבר או הוראה.

## 3. קח
**מה:** להעתיק את מה שיש בכתובת. המקור נשאר.
**כמה סוגים:** אחד.
- «קח והעלם מהמקור» = קח + שים-ריק. שתי פעולות, לא סוג חדש.

## 4. שים
**מה:** לכתוב ערך בכתובת. מה שהיה שם נמחק.
**כמה סוגים:** אחד.
- «מחק» = שים-ריק.
- «הוסף לסוף» = חשב (איפה הסוף) + שים.

## 5. חשב
**מה:** לקחת ערכים ולהוציא ערך חדש.
**כמה סוגים:** נראה כמו הרבה (חיבור, חיסור, כפל, השוואה, «וגם», «או», «לא»…). בפועל אחד:
- כל חישוב נבנה מפעולה אחת: **«לא-וגם»** (NAND) — מקבלת שני ביטים, מחזירה 0 רק אם שניהם 1.
- «לא», «וגם», «או» ⇐ מ«לא-וגם». חיבור ⇐ מהם. חיסור, כפל, השוואה ⇐ מחיבור ומהם.
- «השווה» = חשב (האם ההפרש 0). לא פעולה נפרדת.

---

## מה **אינו** פעולת-יסוד (מתפרק ל-5)

| פעולה | מתפרקת ל |
|---|---|
| תביא | לאן ⇒ לך ⇒ קח |
| אם (אם כן לך לכאן, אחרת לשם) | חשב (לאיזו כתובת, לפי התנאי) ⇒ לך |
| חזור על (לולאה) | … ⇒ חשב (האם לסיים) ⇒ לך (להתחלה) |
| חפש ברשימה | לאן ⇒ לך ⇒ קח ⇒ חשב (שווה?) ⇒ חשב (הבא בתור) ⇒ לך … |
| קרא קובץ | לאן (שם הקובץ) ⇒ לך (לטבלת הקבצים) ⇒ קח (כתובת) ⇒ לך ⇒ קח |
| כתוב קובץ | לאן ⇒ לך ⇒ קח (כתובת) ⇒ לך ⇒ שים |
| מחק | שים-ריק |
| הרץ תוכנה אחרת | לאן (תחילת התוכנה) ⇒ לך |

## הפירוק של שורה 6 במנוע `app-from-sentences.mjs`

```
import fs from 'node:fs';
```

1. **לאן** — השם `node:fs`
2. **לך** — לטבלת השמות של Node
3. **קח** — את הכתובת של הכלי
4. **לך** — לכתובת
5. **קח** — את הכלי
6. **לאן** — המקום `fs`
7. **לך** — לשם
8. **שים** — את הכלי

**5 פעולות-יסוד: לאן · לך · קח · שים · חשב.**
