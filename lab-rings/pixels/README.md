# pixels — תמונה ⇒ קוד שמצייר אותה בדיוק (0 פיקסלים שונים)

- `image_to_code.py` — הבסיס: שורה לכל פיקסל (`pixels`) או לכל רצף צבע (`runs`). חומה 540×675: 15.6MB / 3.8MB.
- שלושה מנועים שמחפשים תוכנית קצרה (פייתון + Pillow + ספרייה סטנדרטית בלבד; התוכנית לא קוראת שום קובץ):
  - `shapes/` — רקע + מלבנים/שורות-חוזרות + מקודד-אריתמטי עם התאמת-טלאים. `python3 engine.py IMG out.py --verify`
  - `predict/` — חיזוי מהשכנים (median-edge, קו-צבע) + קידוד שגיאות; מקודד ב-C (pxenc.c). `python3 engine.py IMG out.py [--search] --verify`
  - `dict/` — מילון טלאים חוזרים + LZMA / מקודד-הקשר. `python3 engine.py IMG out.py`
- הרצת תוכנית שנוצרה: `python3 -c "OUT='x.png'; exec(open('out.py').read())"` ואז `python3 compare.py original.png x.png`.
