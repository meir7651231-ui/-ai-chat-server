# lab-rings — מנוע עיגולים על 5 פעולות-יסוד (מעבדה, 27–28.9.2026)

תיקייה נפרדת. לא נוגעת באף מנוע קיים. הכל רץ מכאן.

## מה זה
מנוע שבונה תוכניות **לבד**, רק מדוגמאות («כשנכנס X צריך לצאת Y»), מתוך 5 פעולות-יסוד בלבד:
**לאן · לך · קח · שים · חשב** (ראה `ATOMS.md`). כל מה שנבנה נשמר ונהיה צינור לבנייה הבאה.

## תיקיות
- `ATOMS.md` — 5 פעולות-היסוד, איך הגענו אליהן (פירוק של `app-from-sentences.mjs`).
- `APP-FROM-SENTENCES-HE.md` — תרגום המנוע הראשון לעברית, שורה-שורה.
- `lab12/` — **מכונה 1**: תאים של ביט אחד. `rings-atoms.mjs` = מנוע העיגולים. בנה לבד: העתק · לא · וגם · או · שונה · חיבור 2/3 ביטים · שווה · בורר · חיבור מספרים · גדול-מ.
- `lab13/` — **מכונה 2**: תאים של 0..15, «לאן» מחושב (כתובת מתוך תא) ו«לך לשורה» (קפיצה ⇒ «אם» ולולאות).
  - `machine2.mjs` — המכונה. `rings2.mjs` — המנוע (סולם המשימות בסוף הקובץ).
  - `exact.mjs`, `exact-xor.mjs` — חיפוש מלא (שכבה-שכבה, איחוד מצבים) ⇒ הקצר ביותר, מוכח.
  - `smt.py`, `smt_goal.py`, `cegis.py` — הפותר Z3 (`pip install z3-solver`) ⇒ הוכחת «אין קצר יותר» גם עם קפיצות.
  - `lifted-add.mjs` + `fulladder-m1.txt` — «חשב+»: המחבר-המלא שמכונה 1 למדה לבד, מופעל ביט-אחר-ביט.
  - `lib2.json` — **הזיכרון**: כל הלבנים שנלמדו (נטען בכל ריצה).
  - `ladder2-*.log` — תוצאות כל הריצות.

## הרצה
```
cd lab13 && node rings2.mjs          # הסולם; מה שבזיכרון נטען מיד
cd lab12 && node rings-atoms.mjs learn
```
