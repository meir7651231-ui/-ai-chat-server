# vector — תמונה (פיקסלים) ⇒ SVG של צורות שאפשר לערוך ולהגדיל

שני מנועים שנבנו מאפס (בלי ספריית-וקטוריזציה): numpy/scipy/scikit-image + Pillow + Chromium לרינדור.
- `trace/` — אזורי-צבע, גבולות בדיוק תת-פיקסלי, עקומות בזייה, מעברי-צבע. `python3 trace.py IN.png OUT.svg [--smooth]`
- `prims/` — מזהה צורות בשם (מלבן, מלבן-מעוגל, עיגול, אליפסה מסובבת, קו, משולש, מעבר-צבע). `python3 prims.py IN.png OUT.svg`
- `score.py ORIG.png CAND.svg` — מרנדר את ה-SVG ומשווה: close_pct (הפרש ≤24 לערוץ), psnr, מספר צורות, בייטים.
