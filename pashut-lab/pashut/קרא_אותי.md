# פשוט — שפת תכנות בעברית יום-יומית

כותבים בעברית פשוטה. המהדר הופך את הקוד לתוכנה אמיתית שרצה **ישר על המעבד** — בלי Python.

```
שם = שאל("מה שמך? ")
הצג("שלום", שם + "!")
הצג("בשם שלך יש", כמה(שם), "אותיות")
```

## איך מריצים

צריך `python3` ו-`gcc` (רק כדי **לבנות**; התוכנה שנוצרת לא צריכה אותם). לינוקס, או Windows עם mingw — ראו למטה.

```bash
python3 pashut.py examples/שלום.פשוט --הרץ     # בונה ומריץ
python3 pashut.py examples/שלום.פשוט           # רק בונה → examples/שלום
./examples/שלום                                # מריצים — בלי Python
tests/run_all.sh                               # כל הבדיקות (צריך גם python3.12 או חדש יותר, להשוואה)
```

## המילים

| פקודה | משמעות | | פעולה מוכנה | משמעות |
|---|---|---|---|---|
| `אם` / `ואם` / `אחרת` | תנאי | | `הצג(...)` | להציג על המסך |
| `כל עוד` | לולאה כל עוד תנאי נכון | | `שאל("שאלה")` | לקבל טקסט מהמשתמש |
| `לכל x בתוך ספירה(10)` | לולאה על מספרים | | `כמה(טקסט)` | כמה אותיות |
| `לכל אות בתוך טקסט` | לולאה על אותיות | | `מספר(...)` | להפוך למספר שלם |
| `עצור` / `הבא` | לצאת מלולאה / לדלג לסיבוב הבא | | `שבר(...)` | להפוך לשבר |
| `פעולה שם(x, y):` | להגדיר פעולה | | `טקסט(...)` | להפוך לטקסט |

| `וגם` / `או` / `לא` | לחבר תנאים | | `סכום(רשימה)` | לחבר את כל המספרים |
| `בהמשך` | שורה ריקה, ממלאים אחר כך | | `הגדול(...)` / `הקטן(...)` | הכי גדול / הכי קטן (ברשימה או בין כמה ערכים) |
| `לכל x בתוך רשימה` | לולאה על איברים | | `מסודר(רשימה)` | רשימה חדשה מסודרת |
| `לכל מפתח בתוך מילון` | לולאה על המפתחות | | `מפתחות(מילון)` / `ערכים(מילון)` | רשימת המפתחות / הערכים |
| `מבנה שם:` | סוג משלך (שדות + פעולות) | | `עגל(x)` / `עגל(x, 2)` | עיגול (חצי לזוגי, כמו Python) |
| `נסה:` / `אם נכשל:` | לטפל בשגיאה בלי לעצור | | `קוד_אות("א")` / `אות_מקוד(1488)` | אות ↔ מספר |
| | | | `שגיאה("הודעה")` | לעצור עם שגיאה משלך |
| | | | `קרא_קובץ` / `כתוב_קובץ` / `הוסף_לקובץ` / `קיים_קובץ` | קבצים |
| | | | `ארגומנטים()` | מה שנכתב אחרי שם התוכנה |
| | | | `במקביל(פעולה, רשימה)` | על כל הליבות |
| | | | `כותרת`, `כפתור`, `שדה_קלט`... | בניית דף אינטרנט — ראו "אתר" |

**סוגים:** `מספר` (שלם) · `שבר` · `טקסט` · `לוגי` (נכון/לא נכון) · `רשימה של ...` · `מילון מ... ל...` · מבנה שהגדרת. הסוג נקבע לבד מהערך הראשון.
הסוג של פרמטר נקבע לבד לפי מה ששולחים לפעולה. אפשר גם לכתוב אותו: `פעולה ברך(שם: טקסט):` · `פעולה ממוצע(ציונים: רשימה של מספר):` · `פעולה דוח(ציונים: מילון מטקסט למספר):`

## רשימות

```
ציונים = [90, 85, 77]
ציונים.הוסף(100)            # להוסיף בסוף
אחרון = ציונים.הוצא()       # להוציא את האחרון
הצג(ציונים[0], ציונים[-1])  # הראשון, האחרון
ציונים[1] = 88              # לשנות איבר
אם 90 בתוך ציונים:          # האם נמצא
    הצג(כמה(ציונים), סכום(ציונים), הגדול(ציונים), מסודר(ציונים))
ריקה = []                   # הסוג ייקבע לפי מה שיוסיפו לה
לוח = [[1, 2], [3, 4]]      # רשימה של רשימות
```

* כל האיברים ברשימה מאותו סוג. `[1, "א"]` — שגיאה לפני ההרצה.
* `+` מחבר רשימות, `==` משווה.
* רשימה שמעבירים לפעולה, או ששמים במשתנה אחר, היא **אותה רשימה** (כמו ב-Python): מה שמוסיפים דרך שם אחד רואים גם בשני.
* מקום שלא קיים (`ציונים[10]`), הוצאה מרשימה ריקה, `הגדול` של רשימה ריקה — עוצרים עם הודעה בעברית ומספר שורה.

## מילונים

```
ציונים = {"דנה": 90, "משה": 85}
ציונים["רותם"] = 77              # להוסיף או לשנות
ציונים["דנה"] += 5
הצג(ציונים["דנה"])               # 95
אם "משה" בתוך ציונים:            # האם יש מפתח כזה
    ציונים.הוצא("משה")           # להוציא (ומקבלים את הערך)
הצג(ציונים.קבל("נועה", 0))       # 0 — אם אין מפתח כזה, הערך השני
לכל שם בתוך ציונים:              # לפי סדר ההוספה, כמו ב-Python
    הצג(שם, ציונים[שם])
הצג(מסודר(ציונים), מפתחות(ציונים), ערכים(ציונים), כמה(ציונים))
```

* מפתח יכול להיות מספר, טקסט או נכון/לא נכון. כל המפתחות מאותו סוג, וכל הערכים מאותו סוג.
* מפתח שלא קיים (`ציונים["אבי"]`) — עוצרים עם הודעה. אם לא בטוחים, `.קבל(מפתח, ברירת מחדל)`.
* אסור להוסיף או להוציא מפתחות בזמן לולאה על אותו מילון (מותר לשנות ערכים) — עוצרים עם הודעה, כמו Python.

## מבנים — סוג משלך

```
מבנה תלמיד:
    שם: טקסט
    ציון: מספר
    כיתה: טקסט = "א"             # ערך התחלתי (לא חובה)

    פעולה תאר():                 # בתוך מבנה, "זה" הוא התלמיד עצמו
        תן זה.שם + ": " + טקסט(זה.ציון)

ת = תלמיד("דנה", 90)
ת2 = תלמיד(שם="משה", ציון=85)    # אפשר גם לפי שמות
ת.ציון += 5
הצג(ת)                           # תלמיד(שם='דנה', ציון=95, כיתה='א')
הצג(ת.תאר())
```

**מיון לפי כלל:**
```
פעולה ציון_של(ת: תלמיד):
    תן ת.ציון
מסודר(כיתה, לפי=ציון_של)             # מהנמוך לגבוה
מסודר(כיתה, לפי=ציון_של, הפוך=נכון)  # מהגבוה לנמוך
הגדול(כיתה, לפי=ציון_של)             # התלמיד עם הציון הכי גבוה
```

## לטפל בשגיאות

```
נסה:
    גיל = מספר(שאל("בן כמה? "))
אם נכשל עם הודעה:
    הצג("זה לא מספר:", הודעה)
    גיל = 0
```
כל שגיאה בזמן ריצה (מקום שלא קיים, קובץ שלא נמצא, חלוקה באפס, `שגיאה("...")` שלך) — נתפסת.

**חשבון:** `+ - * /` (חילוק תמיד נותן שבר) · `//` (חילוק שלם) · `%` (שארית) · `== != < > <= >=` · אפשר `+=`, `-=`, `*=`.

## מה מובטח

* **מהירות (מול Python 3.13, אותו פלט בדיוק):** חשבון ולולאות (`examples/מהירות.פשוט`) — **פי 47**. רשימות (`examples/רשימות.פשוט`) — **פי 7**. מילונים (`examples/מילונים.פשוט`) — **פי 5**. עבודה כבדה על טקסט — בערך כמו Python. קריאות ל-Python — פי 2 יותר איטי מ-Python.
* **אותן תוצאות כמו Python:** 25 תוכניות, ועוד תוכניות אקראיות (חשבון, רשימות, מילונים, חיתוך, טקסט עם אותיות נדירות, מבנים — אלפי שורות בכל הרצה) הושוו מול Python 3.13 — זהות. נבדק גם בהגרלות נוספות.
* **אותו סדר כמו Python:** בביטוי כמו `f(1) + f(2)` — קודם f(1). ב-`הצג(...)` — קודם מחשבים את הכל, אחר כך מדפיסים.
* **אין תוצאות שגויות בשקט:** חלוקה באפס, מספר גדול מדי, טקסט שאינו מספר, רקורסיה אינסופית, מקום שלא קיים ברשימה, מפתח שלא קיים במילון — עוצרים עם הודעה בעברית ומספר שורה.
* **טעויות נתפסות לפני ההרצה:** חיבור טקסט למספר, משתנה שלא קיים, רשימה עם סוגים מעורבים, רשימה כמפתח של מילון — 122 מקרי שגיאה נבדקים.
* **בדיקת זיכרון:** כל תוכניות הבדיקה (וגם האקראיות) עברו את הכלים שתופסים גישה לזיכרון לא שלך (AddressSanitizer, UndefinedBehaviorSanitizer) ו-valgrind — אפס ממצאים. מנגנון שחרור הזיכרון נבדק גם ב"מצב עינוי": איסוף אחרי כל הקצאה, והזיכרון המשוחרר מתמלא זבל — אותו פלט בדיוק.

**הבדלים מכוונים מ-Python** (כי כאן לכל דבר יש סוג קבוע):
* `נכון` / `לא נכון` במקום True / False.
* רשימה של שברים: `[0.5, 1]` מודפסת `[0.5, 1.0]`. סכום של רשימת שברים ריקה הוא `0.0`.
* משתנה שהתחיל כמספר לא יכול להפוך לטקסט. פעולה שקיבלה מספר לא יכולה לקבל טקסט בקריאה אחרת.
* `מילון.קבל(מפתח, ברירת מחדל)` — ברירת המחדל חובה (ב-Python אפשר בלי, ואז מקבלים None — כאן אין None).
* שדה מסוג `שבר` שמקבל `1` שומר `1.0`.
* מספר שלם גדול מ-9,223,372,036,854,775,807 — שגיאה (ב-Python אין גבול).
* **עברית לפי אותיות:** `כמה("שלום")` = 4.

## כלום — "אין ערך"

```
מבנה צומת:
    ערך: מספר
    הבא: צומת או כלום = כלום      # אולי יש צומת הבא, ואולי לא

ראש = כלום
לכל i בתוך ספירה(3):
    ראש = צומת(i, ראש)
נוכחי = ראש
כל עוד נוכחי != כלום:
    הצג(נוכחי.ערך)
    נוכחי = נוכחי.הבא

פעולה מצא(שמות: רשימה של טקסט, אות: טקסט):
    לכל ש בתוך שמות:
        אם ש.מתחיל_ב(אות):
            תן ש
    תן כלום                       # לא נמצא
```
* `כלום` אפשר רק במקום של טקסט, רשימה, מילון או מבנה (לא של מספר).
* להשתמש בערך שהוא כלום (`x.שדה`, `כמה(x)`, חשבון) — עוצרים עם הודעה, כמו ב-Python.
* `מילון.קבל(מפתח)` בלי ערך שני — נותן כלום אם אין מפתח כזה.

## ספריות של Python

```
ייבא math
ייבא json
הצג(math.sqrt(16.0))
נתונים = json.loads("{\"א\": [1, 2]}")
לכל x בתוך נתונים["א"]:
    הצג(x * 2)
סך = מספר(נתונים["א"][0]) + 10     # מערך של Python למספר שלנו — במפורש
```
* כל ספרייה שמותקנת ב-Python (json, math, datetime, statistics, csv, ...) — עובדת.
* ערך שחוזר מ-Python הוא "ערך של Python": אפשר להציג, להעביר הלאה, לעבור עליו בלולאה, לחשב איתו.
  כדי להשתמש בו כמספר/שבר/טקסט שלנו — `מספר(...)`, `שבר(...)`, `טקסט(...)`.
* שגיאה ב-Python הופכת לשגיאה רגילה — אפשר לתפוס ב-`נסה`.
* ערך של Python מוצג כמו ש-Python מציג אותו (למשל `None` ו-`True` בתוך רשימה של Python).
* **רק תוכנה שיש בה `ייבא` צריכה Python מותקן כדי לרוץ.** כל השאר רץ בלי Python בכלל.
* חישוב שכולו קריאות ל-Python איטי פי 2 מ-Python עצמו (כל ערך עובר המרה); חישוב שלנו — מהיר כרגיל.
* `examples/פייתון.פשוט` — דוגמה.

## במקביל — כל הליבות של המעבד

```
פעולה ראשוניים_עד(n):
    ...
תוצאות = במקביל(ראשוניים_עד, [2000000, 2000001, 2000002, 2000003])
תוצאות = במקביל(ראשוניים_עד, גבולות, עובדים=2)    # כמה ליבות (בלי זה — כולן)
```
* מפעיל את הפעולה על כל איבר ברשימה, על כמה ליבות בבת אחת. התוצאות — באותו סדר כמו הרשימה.
* בבדיקה: 8 חישובים כבדים — ליבה אחת 4.6 שניות, 4 ליבות 1.2 שניות (פי 4), אותה תוצאה.
* כל "עובד" הוא עותק נפרד של התוכנה, אז עובדים לא מפריעים זה לזה (אין "מרוצים" ותקלות מוזרות).
  מה שהפעולה משנה במשתנים של התוכנה — לא חוזר. רק מה שהיא נותנת ב-`תן` חוזר.
* שגיאה בתוך עובד — מגיעה לתוכנה הראשית עם מספר השורה, ואפשר לתפוס אותה ב-`נסה`.
* הדפסות מתוך עובדים יכולות להופיע בסדר מעורבב.

## אתר — דף אינטרנט

```bash
python3 pashut.py examples/קניות.פשוט --אתר      # בונה examples/קניות.html — פותחים בכל דפדפן, גם בטלפון
```
אותה שפה בדיוק. יש כמה מילים לבניית הדף:

| מילה | מה היא עושה |
|---|---|
| `כותרת("...")` | כותרת גדולה (וגם שם הדף) |
| `טקסט_בדף("...")` | שורת טקסט. אפשר לשנות אחר כך: `.שנה("חדש")` |
| `שדה_קלט("רמז", פעולה)` | תיבה לכתיבה. `.ערך()` — מה שנכתב, `.נקה()`. הפעולה (לא חובה) נקראת כשלוחצים Enter |
| `כפתור("טקסט", פעולה)` | כפתור שמפעיל פעולה שלך (בלי סוגריים). כפתורים ברצף — באותה שורה |
| `רשימת_שורות()` | רשימה בדף. `.הוסף("שורה")`, `.נקה()` |
| `כל_כמה(שניות, פעולה)` | להפעיל פעולה כל כמה שניות (שעון, משחק) |
| `לוח(שורות, עמודות, פעולה)` | לוח משבצות. `.קבע(ש, ע, טקסט)`, `.קרא(ש, ע)`, `.סמן(ש, ע, נכון)`, `.נעל(ש, ע)`, `.נקה()`. הפעולה (לא חובה) — כשמשבצת משתנה |

```
כותרת("רשימת קניות")
שדה = שדה_קלט("מה לקנות?", הוסף)
רשימה = רשימת_שורות()
פעולה הוסף():
    רשימה.הוסף(שדה.ערך())
    שדה.נקה()
כפתור("הוסף", הוסף)
```
* `הצג(...)` באתר — כותב שורות בדף. `שאל(...)` — חלון שאלה של הדפדפן.
* `קרא_קובץ` / `כתוב_קובץ` באתר — נשמרים בזיכרון של הדפדפן, ונשארים גם אחרי שסוגרים את הדף.
* הכל בקובץ אחד (.html), בלי שרת. אפשר לשים אותו בכל אתר, או לשלוח.
* `examples/גיליון.פשוט` — אקסל קטן: נוסחאות, סדר פעולות, טווחים (`=סכום(D2:D5)`), זיהוי מעגלים וחלוקה באפס.
* `examples/סודוקו.פשוט` — פותר סודוקו שלם (גם את "הקשה בעולם", בפחות משנייה).
* **נבדק:** כל תוכניות הבדיקה וכל התוכניות האקראיות רצו גם בגרסת האתר — פלט זהה ל-Python; כל 133 הודעות השגיאה זהות מילה במילה.
  `examples/קניות.פשוט` נבדק בדפדפן אמיתי: הוספה ב-Enter ובכפתור, כפילות, שמירה אחרי רענון, ניקוי.
* באתר אין: `ייבא` (ספריות Python), ו-`במקביל` רץ על ליבה אחת.

## Windows

python3 pashut.py תוכנית.פשוט --ווינדוס        # בונה תוכנית.exe — אפשר גם מלינוקס

* מלינוקס צריך את mingw: `sudo apt install gcc-mingw-w64-x86-64`. ב-Windows עצמו — gcc של mingw (למשל דרך MSYS2).

* עוד לא ב-Windows: `ייבא` (ספריות Python), ו`במקביל` על כמה ליבות.
