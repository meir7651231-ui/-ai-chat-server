## 4. הכלים (כולם ב-`machtzev/`, פקודות verbatim)

### 4.1 המשטרה — חובה ירוקה לפני כל commit
```bash
node machtzev/police.mjs --fast   # לכל commit (שניות): wiring·contract·quarry·freeref·pins
node machtzev/police.mjs          # לסוף-גל (דקות): + selftest + mutation
```
**7 שערים** (מקור-אמת `machtzev/gates.tsv`, ran-ledger):
1. `wiring` — אטום לא מייבא אטום · קופסה לא קופסה · לוח רק קופסאות
2. `contract` — לכל אטום חוזה+בדיקה-ירוקה + **סריקת-PII (חוק-6)**
3. `quarry` — כל טיוטה עם מוצא + parse תקין
4. `freeref` — **אפס מזהה לא-מוגדר** (חוק-1; מנוע: `emit/free-ref-scan.mjs`)
5. `pins` — 11 קבצים נעולי-חתימה (`pins.sha256`)
6. `selftest` — כל שער יורה על fixture מורעל + ביקורת-שלילית
7. `mutation` — בדוק-את-הבדיקה (אדום-על-חלול, ירוק-על-אמיתי)

עדכנת קובץ-נעול? הרץ באותו commit: `node machtzev/pins-check.mjs --write`.

### 4.2 מנועי-הפליטה (`machtzev/emit/`)
| קובץ | תפקיד |
|------|-------|
| `ast-js-to-dart.mjs` | **מנוע ההמרה** — parser של TS (`ts.createSourceFile`), הולך על ה-AST ופולט Dart (`dynamic` + טבלת-stdlib: `.filter`→`.where`, `Math.round`→`_round`, `||`→context-aware, getMonth 0↔1). `export function emit(src)` |

| `fuzz-parity.mjs` | **פאזר-דיפרנציאלי** — מריץ JS(אורקל)+Dart על קורפוס-קצה, משווה. תפס באג-סימן-ה-RTL שגולד+אדוורסרי פספסו. |
