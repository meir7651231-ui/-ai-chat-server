### 2א · המשמר (‏`isGoalVerb`) — שתי חוליות שלא נקראו

```js
const GRAMW = new Map([ …lexicon.json (120 מילות-חלק ⇒ תפקיד)…,
                        …spec-lang: sectionMarkers/stagePrefixes/markRules/markDelete/markGuards/entityNouns… ]);
if (GRAMW.has(w)) return false;   // מוצהרת כדקדוק-שפת-האפיון ⇒ אינה פועל
```

‏**לא** צורף ל-`SCAF`: ‏`SCAF` מסנן גם את `contentW`, ושם «תאריך» · «מספר» · «כתובת» הן
רמזי-טיפוס אמיתיים ודרושות. זהו משמר של פועל בלבד.
אימות: `isGoalVerb('שלבים')=false` · `isGoalVerb('לשוניות')=false` · `isGoalVerb('לשלוח')=true` · `isGoalVerb('לדעת')=true`.

### 2ב · הקורא שחסר (‏`declaredDemands`) — תביעה **מוצהרת**, עם מוצא

`isGoalVerb` הוא מבחן-**צורה**, ולכן רואה רק שם-פועל. תביעות שכבר הוצהרו **במפורש**, בשפה
שהמחולל עצמו כותב וקורא, היו בלתי-נראות לו. שלושה מקורות, כולם קיימים בדיסק, כולם נותנים `src`:

| # | הצהרה | מוצא | תביעות בקורפוס |
|---|---|---|---|
| 1 | `<סימן>: ע1, ע2…` | `spec-lang.data.json:stagePrefixes/sectionMarkers` — והמחולל כבר בונה מהן מכונת-מצבים (שער `coredart`) | **84** («שלבים») |
| 2 | `<מילת-חלק> … (fnName)` | **האטום עצמו**: חייב להיות שכבת-לוגיקה ב-`atom-index-full.json`, ומילת-החלק ב-`lexicon.json` | **89** («חישוב») |
| 3 | חלק בתפקיד-פעולה | `spec-lang:pAct` ∩ `lexicon` ⇒ `{button}` ⇒ `{כפתור, פעולה}` — **נגזר, לא נבחר** | **6** («כפתור») |

מקור-2 הוא התחביר שהמחולל **פולט בעצמו** (`entity.mjs:142` · `genesis-gen.mjs:239` «⇒ האטום
המדויק»). דוגמה חיה:
```
node -e '…demandsOf("חישוב תיעוד פעולה (runAudit)")…'
⇒ verb "חישוב" · src "new/dart-maor/run-audit.dart (runAudit) · knowledge/lexicon.json:calc"
```
שם שאינו במדף ⇒ **אין תביעה** (לא ניחוש). זה מה שמחזיק את מקור-2 מלהיות רשימת-מילים.

מקור-3 אינו בחירת-תפקיד-ביד: `pAct=["פעולה"]` ו-`lexicon["פעולה"]="button"`, ולכן קבוצת
תפקידי-הפעולה **נגזרת** = `{button}`, וממנה `{כפתור, פעולה}`. שיניתי את pAct/lexicon? לא. קראתי.
