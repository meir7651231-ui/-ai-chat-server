## 0. התזה — למה זה כבר 90% בנוי
אפליקציית-הלימוד היא **אותם מנועים** של מאור (חוגים/תורמים/CRM), עם **דאטה מוזרקת אחרת**:

| היכולת שהמשתמש רואה | הפעולה-היסודית | המנוע הקיים שלנו |
|---|---|---|
| רמת CEFR (A1→C1) | דירוג-מסודר | `grade-order` · `lesson-tier-options` · `band` |
| "מילה שבאה לחזרה היום" (Spaced-Repetition) | תור-לפי-מועד-חוזר | **`hok-due`** · `detect-recurring-hok` |
| חזרה על שיעור-שנכשל | תזמון-השלמה | **`makeup-eligibility`** · `pending-makeups` |
| שיעורים-שהושלמו-החודש | ספירה-לתקופה | **`presents-in-month`** · `enroll-count` · `enroll-summary` |
| דשבורד-מעקב-צמוד | גזירת-KPI-חיה | **`cockpit-kpis` · `cockpit-progress` · `cockpit-feed` · `cockpit-queue`** |
| רצף-ימים / "לא-נגעת 5 ימים" | ימים-מאז / בסיכון | `cockpit-days-since` · `cockpit-at-risk` |
| ניבוי-נשירה (Retention) | churn-score | **`intel-churn-from-scan`** · `intel-donor-scan` · `intel-forecast-from-scan` |
| סיווג-לומד (חוזק/חולשה) | RFM/סגמנט | `intel-rfm-from-scan` · `segments-match-segment` · `segment_key_of` |
| אוצר-מילים / רשימות-סינון | סינון/קיבוץ | `filter-*` · `group-options-of` · `group-label-of` |
| התראות-חכמות | טיוטת-תזכורת + שעת-שקט | **`overdue-contact-task-drafts` · `digest_lines` · `quiet-hours`** |
| דוחות-התקדמות תקופתיים | דוח + CSV | `annual-report` · `reports` · `cockpit-csv-rows` |
| מכתב/משוב-AI | הרכבת-פרומפט | דגם `manager_morning_brief_prompt` · `thanks-prompt` · `lib/ai` (שקע) |
| האפליקציה עצמה | הרכבת-מסך מדאטה | **`generator.dart` + `screens.dart`** (שכבת-המניפסט החיה) |

**המסקנה:** ‏hok-due שמזמן הו״ק-של-תורם ≡ מזמן מילה-לחזרה, כי הוא **טהור** (חוק-5) —
"מה שבא-לפי-מועד" הוא **מטרה מוזרקת**. הלימוד = ורטיקל, לא מוצר-חדש.

## 1. הארכיטקטורה — 4 השכבות שלנו (אפס טכנולוגיה חיצונית)
לפי LAW (חוקי-החשמלאי): **אין** Postgres/Firebase/Node/GPT כרכיבי-ליבה. הכל:
```
אטומים (מנועים טהורים)  →  קופסאות (חיווט)  →  לוח-אם  →  מסכים (מניפסט)  →  המחולל
   ~1,000 קיימים            ~200 קיימות         board       screens.dart      generator.dart
```
- **גבולות-IO בלבד כשקע** (חוק-6 + הכרעה-13): TTS/STT (הקראה/זיהוי-דיבור) · דחיפת-התראות ·
  אחסון-מקומי — **לא אטומים**, חיווט-הצבה בלוח-האם. זהו כל מה ש"חיצוני".

## 2. מיפוי-פר-מסך (הרכבה, לא בנייה)

### 2.1 מסך-בית (Dashboard) — **קופסת-קוקפיט**
- יעד-יומי + פס-התקדמות → `cockpit-progress` · `cockpit-kpis`
- גרף-שבועי (זמן/שיעורים/מילים) → `cockpit-feed` · `presents-in-month` · `cockpit-collected-this-month` (מוחלף-מטרה: "נאסף"→"נלמד")
- רצף-ימים 🔥 → `cockpit-days-since` (מטרה: ימים-מאז-פעילות)
- "השיעור-הבא" → `cockpit-queue` (תור-המשימות: השיעור-הבא במקום שיחת-הגבייה-הבאה)
- התראה-בסיכון → `cockpit-at-risk` · `intel-churn-from-scan`

### 2.2 מסלול-למידה (Learning Path) — **קופסת-חוגים**
- עץ-מיומנויות + נעילות → `enroll-status-meta` · `lesson-tier-options` · `grade-order`
- ציוני-דיוק פר-מיומנות → `enroll-summary` · `band`
- מבחן-מיקום → `intel-rfm-from-scan` + `segments-match-segment` (סיווג-רמה מהתשובות)

### 2.3 מנוע-החזרה-המרווחת — **קופסת-הו״ק (verbatim)**
- מילה חדשה נכנסת לתור → `detect-recurring-hok`
- "מה לחזור היום" → `hok-due` (המנוע **זהה** לתור-הו״ק; המטרה="מילה" במקום "הוראת-קבע")
- כמה-נלמד-החודש → `hok-monthly-total` · `hok-recorded-this-month`
- מילה-שנשכחה → `makeup-eligibility` + `pending-makeups` (זכאות-חזרה)

### 2.4 שיעור (Lesson) — **קופסת-שיעור** (חדשה, מחווטת-קיים)
- תרגילים (בחירה/הקלדה) → מנועי-בדיקה קיימים (`enrollment-quote` דגם-הערכה) + **דאטת-שיעור מוזרקת**
- ציון/שגיאות → `enroll-summary` + `errors_json` כמטרה
- הקלטת-דיבור → **שקע-STT** (גבול-IO)

### 2.5 צ'אט-AI — **קופסת-שיחה**
- הרכבת-פרומפט לפי-רמה → דגם `manager_morning_brief_prompt` (מחליפים את תבנית-המטרה)
- קריאת-המודל → **שקע `lib/ai`** (כבר קיים, דורמנטי) — לא אטום (חוק-6)
- תיעוד מילים/שגיאות מהשיחה → `intel-donor-scan` דגם (סריקה→תובנות)

### 2.6 פרופיל + דוחות
- סטטיסטיקות → `annual-report` (מוחלף-מטרה: "תרומות-שנתי"→"התקדמות-שנתית") · `reports`
- ייצוא-נתונים → `cockpit-csv-rows` (שער-ייצוא קיים)

### 2.7 התראות-דחיפה
- טיוטות-תזכורת → `overdue-contact-task-drafts` (מטרה: "לא-נלמד 5 ימים")
- תקציר-בוקר → `digest_lines` · `manager_morning_brief_prompt`
- שעה-אופטימלית → `quiet-hours` (מנוע שעות-נוחות קיים)
- שליחה עצמה → **שקע-דחיפה** (גבול-IO)

## 3. שכבת-הדאטה (היחיד ש"חדש" — וזה **רק דאטה**)
לפי PURPOSE — המנועים לא נוגעים; מזריקים **אטומי-דאטה** חדשים בלבד:
- `english-vocab-terms.dart` — מילים EN↔HE + רמת-CEFR + חלק-דיבר (מבנה `word_en/word_he/cefr`)
- `english-lessons-terms.dart` — תוכן-שיעורים (title/explanation/examples/exercises)
- `cefr-levels-terms.dart` — סף-מעבר פר-רמה (המטרות של `grade-order`)
- `english-prompts-terms.dart` — תבניות-פרומפט לצ'אט (המטרות של קופסת-השיחה)

**מבחן-הקונכייה (חוק-7):** מחק-דאטה → העלה קטלוג-רוסית/צרפתית → **אותה אפליקציה רצה.**
כי המנועים טהורים. זו בדיוק ה-white-label של PURPOSE.

## 4. מה **באמת** דורש אטום-חדש (הכנות — L28)
כמעט-כלום. פורקתי כל יכולת; רק **גבולות-IO** (לא-אטומים בהגדרה) + מעט-מנועים-קטנים:
- ⚙️ **שקעים (לא אטומים):** STT · TTS · pronunciation-score · push · local-store. חיווט-הצבה.
- ⚛️ **אטום-קטן חדש אפשרי:** `srs-interval` (‏1·3·7·21 יום) — אם `hok-due` לא מכסה מרווח-משתנה;
  מפרק ל-`next-review = last + interval[recognition_level]` — פעולת-חשבון, לא כלי-שלישי (L28).
- ה-`recognition_level`/`production_level` (0-5) = דגם `band` (מדרג-לפי-סף) — קיים.

## 5. מפת-בנייה (לפי **הדרך שלנו**, לא 12-חודשים חיצוניים)
1. **דאטה:** 4 אטומי-דאטה (§3) — מכני, אין מנוע.
2. **קופסאות:** קופסת-שיעור + קופסת-שיחה (חדשות) · שאר-הקופסאות = **קיימות, חיווט-מטרה-מחדש**.
3. **מסך + מחולל:** `screens.dart` + `generator.dart` פולטים את המסכים מהמניפסט.
4. **שערים:** משטרה 9/9 (כולל datapurity — האפליקציה תישאר טהורה) + רתמת-זהב + genesis-compile.
5. **cutover** (חוק-7): טוען-לצד, דגל-הפיך.

**היקף אמיתי:** ‏~2 קופסאות-חדשות + ~4 אטומי-דאטה + ~1 אטום-מנוע-אפשרי (`srs-interval`) +
מניפסט-מסכים. **כל השאר — הרכבת-קיים.** זו ההוכחה החיה של המחולל: יכולת-שלמה-חדשה
מ**חיווט + דאטה**, כמעט אפס-מנוע-חדש.
