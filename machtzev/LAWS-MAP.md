### העץ
```
new/
├── atoms/     # קובץ=אטום · אפס imports פנימיים (מותר: שפה/סטנדרט בלבד)
├── boxes/     # מייבאות אך ורק מ-atoms/
└── board.*    # היחיד שמייבא מ-boxes/
```
**האכיפה (wiring-check, 🚨 exit 1):** atoms→atoms · boxes→boxes · boxes מחוץ ל-board · board→atoms ישירות.

**המשמעות להרכבה:** "שילוב הכל-הכל" ≠ מנוע-ממוזג. שילוב = פירוק הכפילים לחוטים + קופסה אחת שמחווטת את כולם. רוצים פחות? מנתקים חוט. האטומים לא נפגעים.
