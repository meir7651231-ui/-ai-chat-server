# 🔤 מנוע-פליטה Dart→JS · prototype (24.8.2026)
הוכחת-היתכנות לרעיון-הבעלים: "מנוע קטן שהופך שפת-קופסה לפי הצורך" — במקום לכבול
את האימפריה לשפה אחת, קטלוג-מקור אחד נפלט ל-web(JS) או Flutter(Dart) לפי המטרה.

## מה הוכח
- `dart-to-js.mjs` — תמורות לניב-האטומים (טיפוסים, final→const, RegExp→literal,
  named-params→destructure, .isEmpty/.isFinite/.abs, is-operator, named-call-args).
- `parity-check.mjs` — **רתמת-זהב אמיתית**: פולט אטום+בדיקה ל-JS, מריץ ב-node; ה-asserts
  שכבר אומתו מול Dart (dart --enable-asserts) הם הקורפוס. עובר ⇒ Dart≡JS מוכח.
- **תוצאה:** 3/26 עוברים זהב-מלא אוטומטית (valid_email · min_bore_of · ...);
  19/26 הם דיאלקט-פונקציה-פשוט (מתכנסים עם עוד כללים); 7/26 class/record/switch (הבניין האמיתי).

## המסקנה
הרעיון **עובד ובטוח**: הניב-הנפוץ מתורגם מכנית, הזהב תופס כל טעות פר-אטום, שקעי-IO
נשארים ניטיביים פר-מטרה. להשלמה מלאה = הבשלת-כללים (class/record/is) — יום-יומיים.
לא מהדר-כללי; מנוע-פליטה לניב-מוגבל עם רשת-זהב.

## מנוע הפוך · JS→Dart (js-to-dart.mjs) — החלפת-שפת-מאור
הכיוון הקשה (חסר-טיפוס→מטופס). טיפוסים נפתרים ב-`dynamic`; **האתגר האמיתי = ספריות-
התקן השונות** (‏JS `.filter/.push/toLocaleString` מול Dart `.where/.add/intl`). טבלת-
מיפוי ב-emitToDart. אימות: `parity-js-dart.mjs` (dart analyze על הפלט).
- **תוצאה נמדדת:** 268/681 אטומי-מאור בניב-נקי; מתוך מדגם — 50% מתקמפלים ב-Dart אחרי
  סבבי-מיפוי ראשוניים, מטפס עם כל כלל (‏.push→.add, for-of, ‏.filter→.where...).
- **הזנב הקשה (הכרעת-אמת):** ‏`toLocaleString('he-IL')` (פורמט-מספר-עברי — אין מקבילת-
  Dart נקייה, דורש חבילת-intl או שקע) · סמנטיקת `||` · map/set-literals. אלה דורשים
  שיפוט פר-אטום ⇒ **המסלול המעשי: מנוע למכני (50%+) + נחיל-סוכנים לזנב, עם ה-JS כזהב.**

## מנוע-מורכב · AST (ast-js-to-dart.mjs) — הדור-השני
במקום רגקס — **הליכה על עץ-התחביר** (מפרש-TypeScript). עדיף מהותית: עדיפויות/קינון/
scope נכונים, ו**ניתוח-הקשר** שרגקס לא יכול:
- `||` בוליאני-בתנאי מול ברירת-מחדל-בהשמה (‏|| מול ??) — לפי סוג-האופרנד.
- truthiness של JS (`!x`, `Boolean(x)`) → שקע `_falsy`/`_truthy`.
- **`getMonth()` ‏0-אינדקס → Dart ‏1-אינדקס** — תיקון-סמנטי אוטומטי (בדיוק סוג-הבאג
  שהזהב קיים בשבילו).
- שקעים לזנב-הקשה: `_toLocaleString` (פורמט-עברי), Date-API, Math.
- **נמדד: 47% מ-200 אטומי-מאור מתקמפלים נקי ב-Dart** (analyze), מטפס עם כל צומת/מיפוי.
  ‏~13% מהכשלים = `await` (אטומי-ענן — לא-אטומים-אמיתיים, שייכים ל-io-wiring).
- הפלט **אידיומטי**: `paidOf → .fold(0, ...)` · `shekel → _toLocaleString socket`.

## פסק-דין (שתי הגישות)
מנוע-רגקס: מהיר-לכתיבה, נשבר-על-תחביר, ~50%-עם-רעש. **מנוע-AST: הדור-הנכון** —
מתכנס לאמינות-גבוהה, מטפל בסמנטיקה, אבל הזנב (locale/מוטביליות-עדינה/Date) עדיין
דורש שקעים + אימות-זהב פר-אטום. **המסלול: מנוע-AST למכני (רוב) + נחיל-סוכנים לזנב, זהב מאמת הכל.**
