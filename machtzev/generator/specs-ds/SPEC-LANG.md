# שפת-הספק (specs-ds) — דף מחולל מ-spec-lang.data.json. אל תערוך ידנית (node machtzev/generator/spec-lang-doc.mjs).

## מבנה קובץ
- `אפליקציה: <שם>` · `עיצוב: נייר | כהה` · `שאלה דוח|רשימה|בית: <שאלה>` · `שרשרת: …`
- `ישות / טבלה / טופס <שם> עם <שדה>, <שדה>, …  | שלבים / סטטוסים / מצבים: א, ב, ג | מחיקה: <ישות>=מפל|cascade|ניתוק | מעברים / שערים: <שלב>: <תנאי> | מיון: <שדה> עולה / מהנמוך|יורד / מהגבוה, <שדה2>` (מיון רשימת-הישות; שדה-בחירה ⇒ סדר-ההכרזה)
- `לוח בקרה עם מונה / count(<ישות>), מונה / count(<ישות>: <שדה>=<ערך>), סכום / sum / Σ(<ישות>.<שדה>)`
- `חלקיק <ישות>: <צורה>` · `דוח <ישות>: <שם> = …` · `תוכן <קבוצה>: <טקסט>`

## שדות (בתוך שורת-הישות)
- חובה `שם*` · ייחודי `שם!` · בחירה-סגורה `שדה{א|ב|ג}` · ברירת-מחדל `שדה[ערך]` · טווח `שדה(0..100)`
- טיפוס לפי מילה בשם: תאריך תאריך / מועד / יום / לידה / תוקף / התחלה / סיום / מתי · מספר מחיר / סכום / תקציב / עלות / כמות / מספר / אחוז / שעות / שטח / רווח / יתרה / מ״ר / מ"ר · כן/לא האם / פעיל / סטטוס / מצב / חסום / מאושר / נכלל · טלפון טלפון / נייד / פלאפון · שעה שעה · אחוז אחוז / אחוזים / ריבית · מקום מקום / כתובת / מיקום · רב-שורתי תיאור / הערה / הערות / פירוט
- **שדה מחושב** `שם = <נוסחה>`: שדות-אחות, מספרים, + - * / ( ) ופונקציות: sqrt(…), min(…), max(…), pow(…), abs(…), round(…), floor(…), ceil(…) (למשל `מרחק בקמ = sqrt(מרחק בריבוע)`, `תקרה = max(תקרה א, תקרה ב)`)
- **שדה מותנה** `שם = <שדה> <op> <שדה|מספר> ? <ערך-אם-כן> : <ערך-אם-לא>` (op: > < >= <=) — למשל `קרוב = מרחק בריבוע < 100 ? קרוב : רחוק`
- קישור לישות-אם: שם-הישות כשם-שדה (`תיק*`)

## חלקיקים (`חלקיק <ישות>: …`)
- `[טבלה / רשימה]` טבלה של כל השדות · **`[טבלה] עמודה, עמודה, … | מיון: <שדה> עולה / מהנמוך|יורד / מהגבוה, <שדה2>`** — עמודות נבחרות ומיון (מספרי כשניתן, ריק אחרון, מפתחות משורשרים)
- `<שם> = מונה / count(<שדה>=<ערך>)` מונה · `<שם> = סכום / sum / Σ(<שדה>)` סכום · `<שם> = ממוצע / avg(<שדה>)` ממוצע · `A מול / vs B` השוואה · `A / B` יחס
- `[ריק] <טקסט>` מצב-ריק · `[פעולה] <טקסט>` כפתור-פעולה · `[איתור / חיפוש]` · `[חריגה / סינון]` · `[ייצוא]`
- `<שם> = [מספר] <טקסט>` "המספר שלך" · `<שם> = [הודעה] <שדה-בחירה> = [תוכן <קבוצה>]` הודעה · `<שם> = [לוח / תאריכים]` לוח-תאריכים · `<שדה>` לבד = עובדה/חלוקה-למצבים
- `<שם> = [תוכן <קבוצה>]` תוכן-קבוע מקבוצת `תוכן <קבוצה>: …`

## דוח (`דוח <ישות>: …`)
- `<שם> = <שדה>` · `<שם> = [תוכן <קבוצה>]` · `[ייצוא] <שם> = <שדה-טלפון>, <טקסט>` (שליחה)
