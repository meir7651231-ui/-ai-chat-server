# פרסום הדף לערוץ

הדף אינו קובץ שמוגש מ-CDN. הוא ארטיפקט של claude.ai, וממנו הוא מקבל את המסד
(`window.claude.use('db')`). לכן אין API ציבורי שמאפשר ל-CI לדחוף אליו,
ובשלב הזה הפרסום ידני — אבל מתועד, ומשאיר קבלה.

1. `node liba/build.mjs` — בונה את `dist/liba-call.html` ואת `liba-call.html` מ-`liba/src`.
2. `node gates/run.mjs` — כל השערים, כולל 49 הבדיקות החיות.
3. קומיט. הקבלה חייבת להצביע על קומיט שמכיל בדיוק את מה שמתפרסם.
4. פרסום עם כלי ה-Artifact, **עם ה-url מתוך `ship/artifact.json`**.
   פרסום בלי ה-url יוצר ארטיפקט חדש עם מסד ריק ומנתק את הבועה מכל ההיסטוריה.
5. `node ship/page-receipt.mjs` — כותב ל-`ship/published.json` את מספר הדף, ה-hash, הקומיט והזמן.
6. קומיט של הקבלה.

`gates/page-version.mjs` נכשל כל עוד הבנייה האחרונה לא פורסמה, כך שפרסום שנשכח
הוא כשל גלוי ולא שתיקה. האוטומציה של השלבים האלה נכנסת בצעד `ship-pipeline`.
