## שלב 1 · העתק תיקייה אחת

צור תיקייה `harness` בשורש הפרויקט ושים בה את שלושת הקבצים:

```
הפרויקט-שלי/
├── harness/
│   ├── police.mjs      ← השער: מכריע DONE / NOT DONE
│   ├── guard.mjs       ← המניעה: חוסם נזק שאין ממנו חזרה
│   └── run.sh          ← הלולאה: מריץ סוכן עד שהשער ירוק
├── src/
└── package.json
```

```bash
chmod +x harness/run.sh
```

## שלב 2 · הרץ פעם אחת (מזהה את הפרויקט לבד)

```bash
node harness/police.mjs --init
```

הוא יזהה אם זה npm / Flutter / Python / Go / Rust, ימצא את פקודת-הטסטים שלך, ויכתוב `harness.json`.
אם הוא כותב `⚠ לא נמצאה פקודת-טסטים` — פתח את `harness.json` ומלא ידנית את `"verify"` עם פקודת-הטסטים שלך. זה השער הכי חשוב.

## שלב 3 · תן משימה

```bash
harness/run.sh -s '^src/cart' "תוסיף הנחת-אחוזים לעגלה, עם טסט"
```

וזה כל מה שצריך לדעת. מה שקורה מאחורי הקלעים, לפי הסדר:

| | |
|---|---|
| 🌳 | נפתח **עץ-עבודה מבודד** על ענף חדש. הקוד שלך לא נוגע עד שאתה ממזג |
| 📌 | **בסיס** — חתימת sha256 על כל קובץ, לפני שהסוכן נגע |
| 🔒 | **דריכה** — פקודות הרסניות בהסגר, commit חסום, השופט נחתם |
| 🔨 | **הסוכן עובד**, ומקבל בהנחיה את חוזה-השער |
| 🚔 | **המכונה מכריעה.** NOT DONE ⇒ הדו"ח שלה נזרק חזרה לסוכן: "תקן בדיוק את זה" |
| 🔁 | חוזר עד DONE או עד תקרת-הסבבים (`-k`, ברירת-מחדל 3) |
| 🔓 | **שחרור** — כל מה שהוסגר חוזר בדיוק כפי שהיה, ונוצר commit על הענף |

בסוף אתה מקבל שורה אחת: `DONE` או `NOT DONE`, ופקודת-מיזוג להעתקה.

**דגלים:** `-m <מודל>` · `-s <רדיוס>` · `-k <סבבים>` · `-t <שניות לסבב>` · `--here` (בלי עץ-עבודה) · `--print` (רק מדפיס את ההנחיה, בלי להריץ).

## אין לך `claude` בשורת-הפקודה?

```bash
harness/run.sh --print -s '^src/cart' "המשימה שלך"
```

מדפיס את ההנחיה המלאה — הדבק אותה ב-Cursor / Copilot / ChatGPT. השער נשאר אותו שער, רק שאתה מריץ אותו:

```bash
node harness/police.mjs --baseline                                  # לפני
node harness/police.mjs --scope '^src/cart' --claims claims.json    # אחרי
```

או חבר CLI אחר ללולאה: `HARNESS_AGENT_CMD='my-cli --file "$PROMPT_FILE"' harness/run.sh "…"`.

## מה תראה

```
| שער | תוצאה |
| in_scope            | ❌ |   ← נגע בקובץ מחוץ למשימה, עם השם
| verify              | ✅ |
| tests_not_weakened  | ❌ |   ← השבית טסט כדי שזה ייראה ירוק
| no_secrets          | ✅ |
...
## פסק: NOT DONE — חסר: in_scope, tests_not_weakened
```

**15 שערים, אפס הגדרות.** שניים מהפרויקט שלך (מה השתנה · הטסטים), 12 שתופסים כשלי-סוכן בכל שפה, ואחד ששומר על השער עצמו:
טסט שהוחלש · סוד בקוד · `console.log` שנשאר · `catch {}` ריק · תלות חדשה · קובץ שנמחק ·
`--force`/`--no-verify` · נתיב-מוחלט · קובץ-נעילה · קובץ ענק · רשת בטסט · ייצוא ציבורי שנעלם · חבלה-בשופט.

ובנוסף: כל טענה שהסוכן כותב ב-`claims.json` מסומנת **CONFIRMED / FALSE / UNVERIFIED** מול השער שהיא נוקבת בשמו.

## מה חסום ולמה

`guard.mjs` נדרך אוטומטית לכל ריצה. הוא מונע מראש את מה שאי-אפשר לתקן בדיעבד:

| | |
|---|---|
| פקודה הרסנית שלך | מוחלפת בבדל שיוצא עם הסבר, ומוחזרת בדיוק בסוף. הוסף ל-`harness.json`: `"guard": {"quarantine": ["scripts/reset-db.js"]}` |
| `git commit` / `push` של הסוכן | חסום — הסוכן לא כותב את ההיסטוריה שעליה שופטים אותו |
| עריכת `harness.json` או המנוע | נחתם בדריכה. שינוי ⇒ `harness_intact` ❌ |
| בסיס חדש באמצע משימה | מסורב, וגם נעול ברמת-הקובץ |
| 41 פקודות מסוכנות | `rm -rf`, `sudo`, `git reset/checkout/stash`, `kubectl`, `terraform apply`, `aws`, `gcloud`, `ssh`, `npm publish`… |

פקודות-הפרויקט שלך (`build`, `verify`, `gates`) מותרות אוטומטית.

## מה זה **לא** עושה

לא מתקן במקום הסוכן. לא הופך אותו לחכם. לא בודק שהקוד עושה את הדבר הנכון — רק שלא שבר משהו שכבר נבדק, שלא לקח קיצור-דרך, ושלא שיקר.

**מה שכן:** אתה מפסיק לעבוד בעיוורון, ובמדידה על 50 משימות אמיתיות מודל זול עלה מ-40 ל-46 מתוך 50 בזכות הלולאה בלבד — ומספר הדו"חות שהכילו טענת-שקר ירד מ-21 ל-אפס.

## להתקדם

`harness.json` הוא הקובץ שמלמד את המנוע על הפרויקט שלך. אפשר להוסיף:
- `"build"` — פקודת-בנייה ⇒ נפתחים עוד שני שערים (הבנייה עוברת · אף אחד לא ערך ידנית קובץ מחולל)
- `"gates"` — בדיקות שכבר יש לך (lint, format)
- `"forbid_in_diff"` — תבניות שאסורות **אצלך** (זה מה שהופך את השער לחזק באמת)
- `"guard": {"quarantine": [...]}` — הפקודות שאתה לא רוצה שסוכן יריץ לעולם

כל באג שתופס אותך פעם אחת — הפוך אותו לשער, והוא לא יחזור.
