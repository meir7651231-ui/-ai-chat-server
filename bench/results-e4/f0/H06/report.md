## Why it sorts as numbers
- `מחיר` is typed `num` by the spec grammar (word-based typing), input via `DsNumberField`, which
  only admits `[0-9.-]`, so stored values parse with `num.tryParse`.
- The emitted comparator (from `sort-cmp.mjs`, L105): empty last, then `num.tryParse` on both
  sides → `nx.compareTo(ny)`; text compare only as a fallback when a value is not numeric.
- JS mirror of the emitted lambda on sample records gives `9 < 3000.5 < 42000 < 100000 < ∅`,
  whereas text order would give `100000 < 3000.5 < 42000 < 9`.
