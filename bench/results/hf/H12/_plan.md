# Plan: Sort Cases Table by סיווג Field

## Goal
Make the cases (תיקים) table in the peruk17 app display cases sorted alphabetically by the סיווג field.

## 10-Step Decomposition

1. **Identify the generator code** — Found: `machtzev/generator/particles.mjs` line 385-389 handles `kind === 'table'`
2. **Understand current behavior** — The rows are generated directly from `recs` (appStore records) without sorting
3. **Find the סיווג field in schema** — It's the 6th field (index 5) in the entity schema for "תיק" 
4. **Determine sort order** — Alphabetical sort of the field values
5. **Locate sorting point** — In the particles.mjs `rows` variable generation, need to sort `recs` before creating rows
6. **Implement sorting logic** — Add `.sorted((a, b) => (a[fieldKey] ?? '').compareTo(b[fieldKey] ?? ''))` to the Dart code
7. **Test the fix** — Run police-bench to verify the generated code is correct
8. **Verify byte correctness** — Check that only the generated files changed, not specs or engine
9. **Write learnings** — Document the sorting pattern in LEARNINGS.md
10. **Run final police check** — Confirm all gates pass
