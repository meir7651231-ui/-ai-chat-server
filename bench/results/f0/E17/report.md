# Report: peruk21 empty-state text

## Task
Change the empty-state text of the case (תיק) screen in `specs-ds/peruk21.txt`
from «אין תיקים עדיין» to «אין מכתבים פתוחים» without breaking anything.

## Why a direct spec edit was not enough
`specs-ds/peruk21.txt` is generated by `machtzev/generator/peruk.mjs` from
`peruks/peruk-21.md` plus `peruk-lang.data.json`. The `peruk` police gate
(`peruk.mjs --gate`) fails whenever the on-disk spec differs from the generator
output, and `peruk.mjs --all` would have overwritten a hand edit. The phrase was a
single global default (`emptyText`) shared by all 28 peruk apps.

## What I changed
1. `machtzev/generator/peruk-lang.data.json`: added `emptyTextBy: { peruk21: "אין מכתבים פתוחים" }`
   next to the existing `emptyText` default (Hebrew stays in data, per §19).
2. `machtzev/generator/peruk.mjs` line 172: empty-state line now uses
   `(P.emptyTextBy || {})[ns] || P.emptyText`.
3. Ran `node machtzev/generator/peruk.mjs --all`: only `specs-ds/peruk21.txt` changed
   (line 12), `peruk-index.json` and the other 27 specs are byte-identical.
4. Ran `node machtzev/generator/app-ds.mjs -f machtzev/generator/specs-ds/peruk21.txt --name peruk21 --skin`
   (exit 0, 8/8 particles wired, 7 screens). Regenerated: `particle-plan-peruk21.{json,md}`,
   `new/dart-gen-bs/gen_app_peruk21_px1.dart`, `new/dart-data-bs/auto/gen_app_peruk21_px1_content.dart`.
5. Ran `node machtzev/pins-check.mjs --write` because `peruk.mjs` is signature-pinned.

Skipped `tighten-types.mjs --record --apply` as instructed (known-broken).
