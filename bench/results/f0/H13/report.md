# Report — table columns from the spec (panuy)

## What I did
1. `machtzev/generator/particles.mjs` — the `[טבלה]` particle shape now accepts an optional
   comma-separated column list, same pattern as the existing `[לוח] שדות?` shape:
   - `shapeOf`: `[טבלה] שם, זמין, מרחק בקמ, מחיר לשעה` ⇒ `{ kind: 'table', fields: [...] }`.
     Bare `[טבלה]` / `[רשימה]` ⇒ `{ kind: 'table' }` exactly as before.

     (fails loud in the plan and the `particles` gate, like `[מספר]` does — no silent guessing).

     otherwise from the full `entity.schema` (unchanged behaviour for all other specs).
