# yeshiva · הקורא הישיבתי — הפיך ונתיק

## מה זה
שכבה 1 בלבד: **צופה**. קורא את מסמכי-הפירוק (`generator/peruks/*.md`) ואת הספקים שנגזרו מהם
(`generator/specs-ds/*.txt`), וכותב לכל פירוק קובץ `out/peruk-NN.yeshiva.md`: מה בפירוק לא הגיע לספק,
ומה הספק הניח במקום הבעלים. אפס מודל, אפס רשת, דטרמיניסטי (אותו קלט ⇒ אותו פלט).

## מה הוא לא עושה (בכוונה)
- לא נוגע בספק, לא בפלט המחולל, לא ב-`regen.mjs`, לא ב-`one.mjs`, לא ב-`gates.tsv`, לא ב-pins.
- לא מייבא שום קובץ של המחצב ושום קובץ של המחצב לא מייבא אותו. החיבור היחיד: קריאת קבצים.
- לא רץ אלא כשמריצים אותו ביד: `node yeshiva/read.mjs --all`.

## הוכחה שהקיים לא נפגע
```bash
node machtzev/one.mjs            # ONE-STATUS.md ו-TRUTH.md זהים לפני ואחרי — הקורא לא בצנרת
node machtzev/police.mjs --fast  # ירוק כמו לפני — התיקייה בשורש הריפו: מחוץ ל-new/, מחוץ ל-machtzev/ (שה-TRUTH סופר את תת-התיקיות שלו וה-INDEX חייב לרשום כל מנוע בו), מחוץ ל-pins
git diff --stat main..claude/yeshiva-read -- . ':!yeshiva'   # ריק: שום קובץ מחוץ לתיקייה לא השתנה
```

## ניתוק מלא (החזרת המצב לקדמותו)
```bash
git rm -r yeshiva
git commit -m "yeshiva: ניתוק"
```
או, בלי commit: `rm -rf yeshiva`. אין שום דבר אחר לנקות — אין רישום ב-regen, אין שער, אין baseline, אין pin.
`node yeshiva/detach.mjs --check` מוכיח את זה: סורק את כל הריפו ומוודא שאף קובץ מחוץ לתיקייה לא מזכיר אותה.
